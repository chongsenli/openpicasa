## 0. 原型总览与导航

### 0.0 工具栏图标形状对照（v1.1，按实装矢量绘制重绘）

HTML 原型的工具栏图标**不是通用 emoji / Unicode 占位**，而是把 `crates/picasa-ui/src/icons.rs` 的 `Icon::*` 矢量绘制逐枚转写成内联 SVG（`stroke=currentColor`，线宽按各图标 `Stroke::new(stroke * k, …)` 还原）。图标到按钮的映射按 `topbar.rs:199-324`，三段分组按 `10` M32-UI-02：

| 段 | 按钮（tooltip） | 实装 `Icon` | 形状（`icons.rs`） | 原占位 → 现 SVG |
| --- | --- | --- | --- | --- |
| 左 | 显示/隐藏边栏 | `SidebarToggle` | 圆角方框 + 内部左侧竖线（`:243`） | `⊞` → 圆角矩形 + 竖分隔线 |
| 左 | 导入：添加文件夹… | `Import` | 托盘开口 + 向下箭头（`:488`） | `＋` → 托盘 + 向下箭头 |
| 左 | 幻灯片（下一版开放） | `Slideshow` | 圆角屏幕 + 播放三角（`:498`） | `▶` → 屏幕框 + 实心三角 |
| 左 | 编辑（下一版开放） | `Edit` | 铅笔：斜杆 + 笔尖（`:512`） | `✎` → 斜置铅笔轮廓 |
| 中 | 方格 | `LayoutGrid` | 2×2 圆角实心方块（`:521`） | `◫` → 2×2 方块 |
| 中 | 纵向瀑布流 | `LayoutMasonryV` | 三列高低错落（`:531`） | `▥` → 三列不等高 |
| 中 | 横向瀑布流 | `LayoutMasonryH` | 三行宽窄错落（`:542`） | `▤` → 三行不等宽 |
| 中 | 缩小缩略图 · ⌘− | `Minus` | 单横线，1.5× 粗（`:236`） | `−` → 粗横线 |
| 中 | 放大缩略图 · ⌘+ | `Plus` | 横 + 竖，1.5× 粗（`:228`） | `＋` → 粗十字 |
| 右 | 搜索 · ⌘F | `Search` | 圆 + 右下柄（`:161`） | `🔍` → 圆 + 柄 |
| 右 | 排序（拍摄日期） | `SortArrows` | 上下箭头并列（`:256`） | `⇅` → 双箭头 |
| 右 | 筛选 | `ListLines` | 三横线，第三行短（`:285`） | `⚑` → 三横线（**注意：筛选不是漏斗/旗帜**） |
| 右 | 更多 | `Ellipsis` | 三个实心点（`:300`） | `⋯` → 三点 |

> ⚠️ 两处**最容易画错**的已按代码核实：① 「筛选」用的是 `ListLines`（三横线），不是漏斗或旗帜；② 「导入」用的是托盘 + 向下箭头（放进图库），不是单纯的加号或文件夹。版权红线不变：**不提取原版资源、不引 SVG 光栅化依赖**（`icons.rs:1-12`），这里只是把本项目自绘的几何图形在 HTML 里重画一遍。
>
> 三屏工具栏（S0 / S8 / S10）使用同一套 SVG；「导入图片」按钮按 `10` M32-UI-01 保留图标＋文字（M3.2 定稿为图标＋文字高频操作），其余为纯图标钮。

### 0.2 全局交互原则（继承 `10`）

| 原则 | 落地 |
| --- | --- |
| 唯一入口 | 「索引管理」仍在底栏最右（`09` §7.5）；不新增第二个入口 |
| 非模态 | 索引管理窗口可关闭，关闭 ≠ 取消任务；后台继续跑，重开接着看进度（`index_mgr.rs:263-266`） |
| 单一真相源 | 窗口内所有数字来自同一个 `MgmtSnapshot`；与主区标题、状态栏数字同源（`M4-IDX-02`） |
| 三级按钮 | 主要操作 ≤1 枚强调填充；常规操作悬浮才出底色；当前状态用浅橙底 `#FBE2D5`（`10` M32-UI-12） |
| 文字层级 | 数值 `text_primary`、标签 `text_secondary`、异常 `warn`/`danger`、禁用 `text_disabled`；对比度 ≥ 4.5:1（`10` M32-UI-13） |
| 不显示 ETA | 进度只给「已处理 N / M」或「已处理 N 项」不确定态（`04` §1.3） |
| 失败不静默 | 失败 / 取消常驻，不自动收起，可重试（R-M2-4） |

**设计要点**

1. **总览摘要区在标签栏之上**，切换任何标签都不消失（`11` §2.1 第 1 点）。字段与来源严格按 `11` §2.1.1 表：根目录逐行（复用 `root_summary_line()` 的 `状态 · N 张 · 占用 · 失败 M` 口径）、索引状态七态、照片数量 `all_photos`、最近更新 `relative_time()`、异常常驻且可点击定位。
2. **0 异常时不渲染整行**（不显示「一切正常」式噪音）；0 个根时显示「尚未添加图库根目录」+ 添加入口。
3. **系统暂停态**显示「已暂停（系统事件，自动恢复）」，**不给「继续」按钮**（`04` P-03）。
4. 第五标签默认名为「导入 / 导出」（P-M4-05 可改为总览区内操作卡片，裁决后回写）。
5. 底部一行**用户语言**的说明，避免出现「staging / schema / WAL / 事务」等内部术语（`10` M32-UI-11 口径）；「事务保护」是唯一例外，且配「失败可回滚」的人话解释。
6. 两枚入口：导出为**主要操作**（当前标签每屏 ≤1 枚），导入为常规操作；符合 `10` M32-UI-12 三级按钮。

```text
   ┌────────────────────────────────────────────────────────────────────┐
   │ 已选 3 张 │ ★ 星标 │ 加标签 ▾ │ 加入相册 ▾ │ 加入托盘 │ 取消选择 │
   └────────────────────────────────────────────────────────────────────┘
   点击「加标签 ▾」 ┌──────────────────────┐
                    │ ☑ 旅行  ☐ 家人  ☐ 工作│  ← 混合状态用「部分选中」样式
                    │ ＋ 新建标签并添加…    │
                    └──────────────────────┘
   点击「加入相册 ▾」┌──────────────────────┐
                    │ ☐ 2026 京都  ☐ 扫描件 │  ← 一张照片可属多个相册，多项可勾
                    │ ＋ 新建相册并加入…    │
                    └──────────────────────┘
```

- 未选中任何照片时**不渲染**该栏（不是隐藏空壳）。
- 批量操作作用于当前选中集：单选 / ⌘ 多选 / Shift 连选计数一致（032-beta4 报告 M32-UI-10 回归）。
- 重复添加去重；移出仅取消归属，不动文件（`M4-ORG-02/08/10`）。
- 删除相册的确认文案必须写「删除相册不会删除照片，也不会删除磁盘目录」（`M4-ORG-07`）。

## 9. 状态机与文案总表

### 9.1 导入/导出共用状态（`11` §2.1.2）

| 状态 | 进度区 | 主按钮 | 是否可关闭窗口 | toast（`M4-BUG-02` 修复后可见） |
| --- | --- | --- | --- | --- |
| 空闲 | 上次操作结果摘要 | 导出 / 选择文件 | 可 | — |
| 准备中 | 「正在准备…」+ 不确定态条 | 禁用 | 可（后台继续） | — |
| 进行中 | `已处理 N / M` + 进度条，无 ETA | 「取消」 | 可（后台继续） | — |
| 成功 | 结果卡片（位置 / 数量 / 耗时） | 「打开所在目录」 | 可 | `✓ 导出成功` / `✓ 导入完成` |
| 失败 | 原因 + 影响范围 + 重试 | 「重试」「返回」 | 可，**不自动收起** | `⛔ 导入失败，现有索引未改动` |
| 已取消 | 「已取消 · 现有索引未改动」 | 「返回」 | 可 | `⏹ 已取消` |

### 9.2 关键文案（统一口径，禁止各处自造）

| 场景 | 文案 |
| --- | --- |
| 全程免责 | 相关操作不修改或移动原始照片 |
| 导入保护 | 导入采用事务保护，失败可回滚 |
| 不含原图 | 原始照片：不包含，且不提供该选项 |
| 取消结果 | 已取消 · 现有索引未改动 |
| 失败结果 | 导入失败 · 现有索引未改动 |
| 路径不匹配 | 路径无法匹配的照片将标记为离线，可在导入后重新匹配图库根目录 |
| 重新匹配 | 重新匹配不会复制、移动或重命名照片；映射后做增量核对 |
| 危险确认 | 照片文件不受影响：不复制、不移动、不重命名 |
| 系统暂停 | 已暂停（系统事件，自动恢复） |

## 11. 设计红线与非目标

| 红线 | 原型如何守 |
| --- | --- |
| 不改三行骨架 | 所有新增只落在窗口内 / 既有弹层 / 左栏分组 / 上下文栏 |
| 唯一入口 | 底栏「索引管理」位置不变，不新增第二入口 |
| 不放假入口 | 左栏标签/相册、筛选面板、上下文栏都只放本版已实现功能 |
| 零写入 | 导出目标校验拦截「落在图库根目录内」；任何界面不提供「包含原图」选项 |
| 失败不静默 | 失败/取消常驻 + 明确「现有索引未改动」 |
| 不显示 ETA | 所有进度条只给 N/M 或 N 项 |
| 数字同源 | 总览 / 标题 / 状态栏 / 结果卡片共用一份快照（原型演示为联动） |
| 非模态 | 关闭窗口 ≠ 取消任务，界面明示 |

**非目标**（不在本原型）：模态对话框、把「诊断」直接删掉而不补齐两项（`M4-BUG-04`）、原图导出开关、AI/人物/地点筛选入口、像素级视觉定稿（归 `docs/ui-baseline`）、深色主题（当前主题单色，沿用 `theme.rs`）。
