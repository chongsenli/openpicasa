# 08-M3 版本说明（0.3.0-beta.1）

**版本定位：规模与实时性版**
**目标规模：100 万张照片**
**发布版本：0.3.0-beta.1 · arm64 · 测试 450 条全绿 · clippy 零告警**

> 本清单按**实际交付内容**编写（已与代码逐项核对）。每节标注与计划稿的差异；
> 计划稿里"明确不包含"的部分若有提前交付，也在文末如实列出。

---

## 一、用户可见功能

### 1. 图库目录管理

- **添加多个照片根目录**：本地目录、外接盘、网络挂载目录均可。
- **渐进式建库**：首批照片落库即可浏览，不等全库扫描完成。
- **扫描进度展示**：已发现数、缩略图完成数、失败数、当前阶段
  （等待 / 扫描中 / 生成缩略图中 / 已完成 / 部分失败 / 暂停 / 不可访问，七态）。
- **暂停 / 继续 / 取消扫描**：暂停停在目录边界，恢复后不重扫。
- **手动重新扫描**：右键单个文件夹或全库重扫，核对新增、修改、删除。
- **目录离线识别**：外接盘拔出时保留索引与缩略图，任务标记「不可访问」并给出原因。
- **重连后增量核对**：L1 目录 mtime 快筛（纳秒精度）+ L2 文件级全校（2 秒容差）两级校验。
- **移除图库根目录**：只删应用内索引，**不碰磁盘照片**。

### 2. 百万级照片浏览

- **虚拟化网格**：只加载可见区域与有限预取。
  实测（100 万行门禁）：首屏 0.29 ms、顺序滚动 p99 17.9 ms（门禁 ≤ 25 ms）。
- **文件夹树 + 「含子文件夹」开关**：递归计数（`total_count` 按子树聚合）。
- **文件夹照片数量显示**。
- **基础排序**：文件名、修改时间、大小、拍摄时间
  （拍摄时间走键集分页；其余排序缺匹配索引，暂用 OFFSET，见 §四）。
- **单选、追加选择（⌘）、范围选择（Shift）**。
- **键盘导航**：方向键、Page Up / Down、Home / End。
- **视口锚点保持**：调整缩略图大小、窗口尺寸、后台更新后滚回原位置。
- **缩略图缺失时显示占位**：不阻塞滚动与选择。

### 3. 缩略图尺寸调节

- **滑块范围 22～512 逻辑 px，12 个档位**：
  22 / 32 / 48 / 64 / 96 / 128 / 160 / 192 / 256 / 320 / 400 / 512。
- **快捷键**：`⌘+` / `⌘−` 按档跳、`⌘0` 回默认。
- **全局保存**（`settings` 表，跟库走）。
- **小尺寸（≤ 48 px）隐藏格内文字**，tooltip 查看名称。
- **按屏幕 DPI 自动选纹理档**（Retina 不糊）。
- **拖动中不换纹理**：拖滑块期间不触发重解码，松手才结算。
- **吸附与回滞**：档位附近吸附防抖动，但不制造「打滑」。
- **22 px 下限 + 微缩图集在本版完整交付**，无 48 px 过渡版。

### 4. 照片格式与缩略图显示

| 格式 | 支持方式 |
| --- | --- |
| JPEG、PNG、BMP | 静态缩略图 |
| WebP、GIF | 静态图 / 动图首帧 |
| TIFF | 首个主图页 |
| HEIC / HEIF | 主图缩略图（纯 Rust 解码器，无 C 依赖、无 unsafe） |
| AVIF | 静态主图缩略图 |
| RAW（CR2 / CR3 / NEF / ARW / DNG 等） | 内嵌预览提取（rawler） |
| SVG | 识别 + 守门（栅格化未在本版交付，进可见失败队列） |

配套：

- **EXIF 八方向处理**（旋转 + 镜像）。
- **透明图片显示**（全链路 RGBA8）。
- **解码前守门**：32 字节魔数嗅探判实际格式（叫 `.jpg` 的 PNG 按 PNG 解），
  80 MP 尺寸预检挡住「30000×30000 的 PNG」这类声明式炸弹。
- **解码隔离（R-M3-10）**：43 个畸形样本实测零 panic、零挂起；
  `catch_unwind` + 按格式熔断，单张坏图不崩主程序、不无限重试。
- **失败可见**：无法解码的文件显示错误占位与**原因短语**（人话，不是错误码）。
- **失败重试**：按文件夹重试或点名重建。

### 5. 目录变化实时反映

- **自动发现新增照片**（FSEvents 实时监视 + 降级轮询，降级在界面可见）。
- **原图修改后自动重生成缩略图**（缓存键：size + mtime + 解码器版本）。
- **文件删除后更新列表与计数**。
- **重命名 / 移动的身份配对引擎**（`MoveMatcher`：size + mtime + 头哈希消歧）
  —— 引擎与 25 条测试已完成，**产品链路接线排下一版**（见 §四）。
- **批量事件合并**：目录级去抖 + 风暴折叠，同一窗口内多次改动只刷一次。
- **监视溢出自动核对**：事件队列满 → 标记 `Overflow`、界面可见
  （角标 + 「为什么？」），等待全量刷新，不静默丢事件。
- **文件写入中延迟处理**。

### 6. 后台任务管理

- **优先生成当前视口缩略图**，屏距淘汰离屏纹理。
- **预取附近照片**（视口前后各 3 屏）。
- **后台补齐全库缩略图**（显式触发，不与启动扫描混跑）。
- **任务暂停 / 继续**（含系统休眠自动暂停、唤醒自动恢复）。
- **异常退出后恢复**：未完成任务以待生成状态保留，下次启动增量续跑。
- **失败任务有限重试 + 按格式熔断**。
- **任务面板**：扫描 / 生成 / 失败 / 暂停原因 / 监视状态一目了然。

## 二、底层新增能力

| 能力 | 交付内容 |
| --- | --- |
| **数据库 v6** | `dir_mtime`（纳秒）、递归计数列、`head_hash`、`format`、`settings` 表 + 六条索引 + 迁移与一致性测试 |
| **大库查询快照** | 首屏 0.29 ms、键集分页 O(log n)、组边界、10 000 组构造 832 ms |
| **异步结果版本校验** | 缓存键 + 解码器版本双重判据，旧结果不覆盖新状态 |
| **三档缩略图管线** | T0 = 512（栅格）/ T1 = 2048（查看器）/ 原图（100% 查看），生成、存储、失效、重建全链路 |
| **CPU / GPU 缓存** | `TextureBudget` 字节账本 + 屏距淘汰 + 内存回滞自保护（SCALE-08） |
| **微缩图集** | 32² 槽 × 4096² 页（16 384 格/页），单槽 `set_partial` 增量上传、整页淘汰、占用同步进预算 |
| **解码隔离** | `catch_unwind` + 按格式熔断 + 尺寸预检，43 畸形样本实测 |
| **有界任务调度** | 优先级、去重、取消、并发限制（4 worker + 专用缩略图池让出一半核） |
| **文件监视与核对** | 多根生命周期、去抖合并、溢出恢复、离线重连、平台探测 |
| **`fs_fuzz` 终态对账** | 随机 10 000 次增删改名移动覆盖，**终态 0 差异**（固定种子可复现） |
| **本地性能诊断** | `m3_bench` 门禁实测工具、帧耗时、队列、缓存统计、诊断页 |
| **安全守卫** | 照片目录零写入、UI 零阻塞 I/O、网格不直接读原图（clippy 规则强制） |

| 图库规模 | 100 万张 | 数据层 100 万行门禁全过 ✅ |

| 解码异常 | 不崩、不永久卡死 | 43 畸形样本 + 10 000 次 fuzz ✅ |

## 四、与计划的差异（必读）

### 比计划多做的（M4 提前交付）

- 收藏（星标）、说明、标签、筛选、时间轴（DB 已升 v7）
- 纵向 / 横向瀑布流视图模式
- HEIC / AVIF / RAW 的**实际解码**（原计划 M3 只做识别）

### 计划内有、本版未交付的

| 项 | 说明 |
| --- | --- |
| 缩略图缩放后锐化 | 未实现 |
| SVG 安全栅格化 | 降级为识别 + 守门 |
| 框选（rubber band） | 未实现 |
| `MoveMatcher` 接入产品链路 | 引擎完成、25 条测试全绿；改名/移动暂按删旧插新处理 |
| 4K 屏微缩图集门禁 | 需 4K 显示器，算式有断言守着 |
| 100 万张真实文件门禁 | 虚拟行已测；真实 IO 门禁待长跑机器 |

### 实现方式与计划不同的

- **键集分页**只覆盖拍摄时间排序（其余排序缺匹配索引，硬走会退化为全表扫描；
  补 `idx_photos_size_id` 等排下一版）。
- **异常退出恢复**靠「待生成状态 + 启动增量扫描」续跑，非显式任务队列持久化——
  用户可感知的效果一致。

---

**一句话总结**：M3 的核心交付——百万库浏览 + 实时目录同步 + 三档缩略图 +
22 px 微缩网格 + 后台任务恢复 + 解码隔离与原图只读保护——全部落地，
并有测试（450 条）与门禁数据背书；5 项顺延（见 §四），3 项 M4 功能提前交付。
