02
对象操作组 ♥收藏 ⓘ说明 ⌗标签 ▣托盘 紧跟「编辑」之后，组尾画 1px 虚线分隔（tray_r.right()+8），与左侧导航钮在视觉上分开。无选中时不置灰不隐藏，点了弹提示。
03
两种角标分置两侧：选中 = 左上实心圆白勾（蓝 #4A90D9，8/8 起 r=7）；星标 = 右上金星（r=(w*0.14).clamp(3.5,7)，垫 black α150 圆）。两者永不重叠（有单测锁定）。
04
云端未下载（M4.3）= 静默灰底 #EDEDED，不写文案、不画云朵角标；有 BLOB 的一律照常出图。原实现：占位写「云端未下载」+ 云朵角标
05
左栏顺序：图库 → 文件夹 → 导入的索引 → 标签 → 相册，底部照片托盘。分组标题右端有「＋」（新建）与「⋯」（排序/显示空标签）。原实现：标签/相册混排、无入口

窗口 1280×820（真实最小尺寸 900×600）。栅格每行 6 格由可用宽度推导，CELL_GAP=16、GRID_PAD=32。

A
排序菜单（宽 180）：八种排序键 + 升降序切换 + 「✓ 有缩略图的排在前面」（M4.3 thumbs_first，默认开）。
B
筛选面板：只看收藏 / 类型 / 尺寸 / 标签 / 相机 / 镜头 / 缺拍摄时间 / 缺元数据 / 文件大小 + 「清除全部筛选」。筛选激活时右段白圆上压 1.5px 选中色描边。
C
更多菜单：添加文件夹… / ✓只看本文件夹 / ✓方格显示文件名 / 全屏 / 关于 OpenPicasa。「只看本文件夹」在无子目录时置灰。
D
搜索展开态：输入框画在上行右侧（宽 240 高 30），带范围钮「文 / 全」——「文」= 当前文件夹，「全」= 全部图库。
01
文件夹树用 Picasa 绿折叠钮 #0A9000，行高 26、缩进 14/级；根节点加粗，离线根整行转灰。悬停出右键菜单（关闭保留索引 / 关闭此文件夹 / 在 Finder 中显示）。
02
导入的索引（M4.3 IDX-21）：每来源一行，在线绿点 / 离线橙点，右键「仅从分组隐藏 / 移除来源」。原实现：无此分组
03
标签组（IDX-22）：组头「＋」新建标签、「⋯」出「按名称/按数量排序」+「✓ 显示空标签」。行尾计数右对齐；非全库视图在计数左侧多画更淡的「·N」（本视图命中数）。名称超宽按字符截断，悬停出全名。
04
内联新建（F1）：点「＋」在组内就地长出输入框 → ⏎ 落库、左栏立即出现新行；Esc 不落库。新建标签要求先选中照片，否则提示「先选中照片再新建标签」。
05
照片托盘：折叠 22 / 展开 92，⌘H 放入，双击打开，右键移出，「清空」在组头右端。
01
圆角统一 8px（THUMB_RADIUS=8）三布局共用；M42-UI-02 的微缩图集圆角把 22px 档也补齐。原实现：瀑布流用 1px 灰框、方格无边框
02
三档缩放 CELL_SIZES=[85,144,200]，用 −/+ 胶囊或 ⌘+/⌘- 切换；已到端点时提示「已是最小/最大缩略图」。每格文件名只在悬停时浮现（`方格显示文件名` 打开后常驻）。
03
瀑布流按短边归列，行高由同一列的累计高度决定；角标与选中态规则完全一致（右上星 / 左上勾）。
01
框选用虚线 + MARQUEE_FILL_ALPHA=0.12 淡蓝填充；DRAG_THRESHOLD=4 像素后才开始，避免误触成点选。
02
边缘自动滚动：进入上/下 30px 边缘带后按距离加速，越靠边幅度越大；只在贴下边时无水平分量。滚轮事件归用户，不被框选抢占。原实现：无边缘滚动，拖出视口即停
03
跨页追加：滚动中新进入视口的格子 union 进已有选中集——不丢旧选中、不重复、顺序稳定（有单测锁定）。
04
累加模式：按住 ⇧ 框选 = 追加；不按 = 替换。
01
三态复选框：全选实心 + 白勾；部分用 45° 半填充（linear-gradient）；未选空心。选中集里若有部分照片带此标签就是「部分」。
02
查询收敛：点开浮层时一次性把「标签 → 计数」读进内存缓存，逐行渲染不再查库；这是 2000 张照片不卡的关键。原实现：每个标签一次 SELECT，浮层开 3 秒
03
底部即时新建：输入框 ⏎ 落库并立即勾上当前选中集；标签行末显示全库计数。
01
两个入口：左栏「相册」组头＋（内联新建）；选中照片后点「加入相册 ▾」下拉选目标（含「新建相册…」）。原实现：只能看不能建
02
右键菜单：打开 / 重命名 / 从相册移出所选 / 删除相册…；删除二次确认文案「只解除关联，不会删除照片文件」。
03
确认框：取消在前且默认聚焦，危险动作用 --danger 实心钮，Esc 等同取消。
01
筛选激活：白圆钮上压 1.5px 选中色描边（不是换底色，保持与其它圆钮同形）。
02
结果视图标题由 view_title() 生成：标签 →「标签：山 · 42 张」；导入 →「本次导入 · 18 张」；星标 →「星标」。副标题由「拍摄时间跨度」生成，无跨度只显示「N 张」。
03
空结果：搜索/筛选无命中时是「没有符合条件的照片 / 当前搜索或筛选没有结果」，与「这里还没有照片」（库为空）区分开。
01
顶栏只有两项：返回、显示位置。其余全走键盘（I 隐藏信息 · Space 切背景 · C 并排 · ←/→ 翻页 · Esc 返回）。
02
底栏信息条：文件名 日期 第 N / M 张 缩放% · 星标 ★★★☆☆ (3) · 标签 chips，超宽收成 +N ▾。原实现：无星标、无标签
03
右侧面板 250px：92px 直方图 + 相机/镜头/焦距/光圈/快门/拍摄时间/时间来源/色彩空间/位置/元数据。无 EXIF 时整块显示「该文件没有 EXIF 信息」，不留空行。
04
加载态：大字居中「正在载入原图…」→「正在解码…」，不显示假进度条。失败显示「元数据读取失败（原因）」。
01
并排比较：C 进入，两图等分，中间 2px 深色缝；任一加载失败只在各自半边显示原因，不影响另一张。
02
无元数据：面板整体显示「该文件没有 EXIF 信息」，直方图区保留但画灰条（不假装有数据）。
03
三态：载入中 / 解码中 / 失败（「元数据读取失败（{}）」）。都不弹模态框，不遮挡翻页。
01
窗口 760×560，非模态，可继续操作主界面。顶部常驻 overview：根目录 / 索引状态 ● / 照片数量 / 最近更新 / 仅 badge>0 才现异常行。
02
任务标签三块：运行中（可见进度 + 暂停/继续/取消）、失败分组（kind.label +「N 条」+ 已忽略 N 仍可见 + 重试全部/忽略全部/取消忽略）、已结束（task_end_summary；空则「没有已结束的任务记录」）。
03
关注文件夹：每根一行，加粗路径 + status_text()（离线用 warn 色）+ root_summary_line + 最多八个操作钮（重新索引（恢复）/在 Finder 中显示/连接后刷新/刷新/重新索引/强制重扫/全量重建/重新打开/关闭）+ 监视状态与「为什么？」+「删除索引」。
04
系统暂停横幅：「系统暂停中（休眠 / 低电量），恢复由系统事件自动发生」——只说明，不提供手动恢复。
01
存储与诊断：索引库文件 / WAL / 缩略图（「N 条 · 大小」或「计算中…」）/ 照片 N 张；下接「清理缩略图」「VACUUM」「清空运行日志」「导出诊断日志」+ 复选框「显示帧时间直方图（p50/p95/p99/max）」。
02
两个清空不混：「清空运行日志」只截断 ~/Library/Logs/app.openpicasa/openpicasa.log；「清空任务历史」在任务标签里，只删 finished_at IS NOT NULL。原实现：一个按钮两件事
03
导入导出：两条中断横幅（导出未完成 / 导入提交前中断已回滚）+ 上次已提交摘要 + 导出区（含「包含缩略图（生成索引包）」）+ 最近成功备份（时间 + SHA-256 前 12 位 + 路径 + 在 Finder 中显示）+ 导入区。页脚「ⓘ 相关操作不修改或移动原始照片 · 导入采用事务保护，失败可回滚」。
04
无 ETA 禁令（IDX-18）：任何提示不得出现「预计」「剩余」「ETA」。校验态文案固定「大文件需要读两遍做完整性复核，期间不会修改任何数据 · 无 ETA」。
01
四步用可选中标签串起来，当前步高亮下划线，已完成步转绿。步骤可回退但不跳步。
02
校验在后台：「正在校验索引文件…（后台执行，界面可继续操作）」+ 动画进度条 + 「取消校验」。sha256 改 1 MiB 分块流式，界面不冻结。
03
进度单调：百分比用上包络，乱序旧快照不得覆盖（单调不回退）；不确定 → 确定的过渡只许进步。
04
合并 / 替换二选一，替换前必须二次确认；导入完成摘要「成功 N · 跳过 N · 失败 N · 冲突 N」。
01
单一入口：不再有独立的「彻底删除」按钮，「删除索引」即彻底删除（用户裁决）。确认框写清「彻底删除」「不能撤销」「无法再重新索引（恢复）」，并给出照片数 / 标记数（未知显示「待计算」）。
02
取消在前且默认聚焦；危险按钮 --danger 实心。确认后连带删 roots 行、刷内存树、清纹理缓存、清孤立导入来源。
03
索引进度浮层：四态互斥（有失败就不叠加暂停标识）；< 1.5 s 完成的任务不出现（避免闪一下）；相对时间 30 秒前 / 10 分钟前 / 2 小时前。
04
状态栏全局进度 pill（IDX-18）：210×4，位于「索引管理」按钮左侧，可点跳「导入/导出」标签。
01
六项：首屏出图时间 / 可见区首张出图延迟 / 滚动帧耗时 p50·p95·p99 / 每帧贴图上传数（上限 3）/ 空白格率 / 掉帧率（frame_ms > 25.0 严格大于）。无样本显示「—（未采样）」，不填 0。
02
锁死常量用 🔒 不用 ✓：3 / 120 / 8.0 三行，表示"不可调"而不是"已验收"。
03
不新增常驻性能 HUD（P5）：诊断窗口是唯一入口，直方图默认关闭，需勾选「显示帧时间直方图」才出现。
01
两种空态不能混：库为空 →「这里还没有照片」+「点顶栏「…」→「添加文件夹…」，选一个放照片的目录（只读，不改你的文件）」；筛选无命中 →「没有符合条件的照片 / 当前搜索或筛选没有结果」。
02
逐格出图：每帧只上传 TEX_UPLOAD_PER_FRAME=3 张，纹理缓存上限 TEX_CACHE_CAP=120；未出图的格子是斜纹占位（placeholder_bg #E4E4E4），不是灰块。
