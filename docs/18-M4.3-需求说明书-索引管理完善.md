## 2. 暂停、继续与取消（M43-IDX-07～09）

**现状**：全局内存暂停与“取消=暂停”不能支持可靠恢复（main `90dca3f` 复核仍如此）。M4.2 的真取消**仅覆盖导入/导出任务**，不覆盖扫描/缩略图任务。

| ID / 优先级 | 怎么改 | 验收标准 |
| --- | --- | --- |
| **M43-IDX-07 P0** 可持久暂停 | 单根任务/全部两个范围；先持久化user_paused意图，再停止领新扫描/缩略图/元数据工作；在途批次安全提交，显示“正在暂停→已暂停”。系统暂停独立reason，系统恢复不覆盖用户暂停；Watcher只记待处理 | 已暂停确认后无该scope索引写入；退出/kill后重开仍暂停，其他根可继续，浏览/打标不受影响 |
| **M43-IDX-08 P0** 继续 | 读取持久队列/检查点继续，不重置为0、不从根重复全扫；目录变更仅失效相应检查点。实时数字仍由一个恢复后的IndexBoard快照发布 | 继续后已提交目录不重复建记录/解码有效缓存；最终照片数与干净全扫一致 |
