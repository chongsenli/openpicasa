## 1. 范围与裁决（唯一来源：`15` v0.4）

### 1.1 定位

M4.2 是 M4 系列走向 `12-RELEASE` 前的**展示打磨 + 展示性能 + 欠账清偿 + 发布收口**小版本：不新造大机制，把 M4 / M4.1 迭代中「为守红线或工作量/技术可行性而明确顺延、诚实登记为未完成」的展示与健壮性欠账清偿掉，外加用户 2026-11-08 直接提出的「图片加载速度 + 滑动平滑度」正向体验目标。**不是 M5（标记+相册）/ M6（排版+查看器）**；本版只做「已记在账上、且属于展示层/交互层/健壮性」的收尾，以及「只接已有 DB 能力的 UI 补全」。

### 1.2 纳入范围（四组，13 条）

| 组 | 主题 | 需求条目 | 优先级 |

- 触板手势框选（P-M42-04）、调整锁死常量（P-M42-09）、预取层级/解码并发等深度改造（P-M42-10）。

## 3. 功能需求

> 每条格式：**编号 / 名称** → 来源、优先级、场景、交互与状态、验收标准（AC）、约束、落点、登记用例。

### A 组 · 展示欠账

#### M42-UI-01 星标/标签可见性

- **来源**：beta.2 release notes、`11`；P-M42-01 已裁决纳入。**优先级 P0**。
- **场景**：用户给照片打星标/加标签后，在网格里能立刻看出来；进查看器能读到该张的完整标记。当前「能打星标、能按星标筛选，但只画选中角标」造成逻辑断裂。
- **交互与状态**：
  1. 网格照片格右上角显示星标角标（0 星不显示；1～5 星显示对应星数/星形），与 `M41-UI-09` 选中角标**共存不打架**：选中态角标与星标角标分占不同角或采用叠加层级，互不遮挡。
  2. 查看器信息条显示该张的**星标**与**标签列表**（多标签可换行/收起， hover 展开全部）。
  3. 标签/星标变更后同帧刷新网格与查看器，无需手动重进。
  4. 空态：无星无标签时信息条不显示空占位。
- **验收标准（AC）**：
  - AC-01 打 3 星 → 网格同格右上出现 3 星角标；取消星标 → 角标消失。
  - AC-02 加 2 个标签 → 查看器信息条显示 2 个；网格标签指示（若有）同步。
  - AC-03 选中该格时，选中角标与星标角标**都可见且不重叠**。
  - AC-04 三布局（方格/纵瀑布/横瀑布）均正确显示。
  - AC-05 与按星标筛选（`PhotoFilter`）组合使用时角标不闪烁、不错位。
- **约束**：不新增 DB 字段/表（R-M42-2）；不引入每帧 `request_repaint()`（R-M41-1）；沿用 v1.8 视觉语言（R-M42-3）。
- **落点**：网格照片格绘制、查看器信息条（§2.4）。
- **登记用例**：`TC-M42-A-01-01`～`TC-M42-A-01-05`。

> **实装口径（2026-11-09 澄清）**：AC-01「打 3 星 → 网格右上 3 星角标」在数据层**不可实现**——只有 0/1 收藏态 `starred: bool`（`crates/picasa-db/src/lib.rs`：`starred: r.get::<_, Option<i64>>(14)?.map(|v| v != 0).unwrap_or(false)`、`UPDATE photos SET starred = ?1`、`AND p.starred = 1`、`starred_ids()`），**没有 1～5 评分列**。在 R-M42-2（不新增 schema/字段）下映射为：`starred=true` → 网格同格右上**单个金色五角星角标** + 查看器信息条「★ 收藏」；`false` 不显示。角标用**自绘 Mesh 五角星**（不依赖「★」字形，字体缺字），与左上选中角标**分置两侧不重叠**。已实装于 `crates/picasa-ui/src/icons.rs`（`star_points` / `draw_star`）、`grid.rs`（`star_badge`）、`viewer.rs`（`draw_star_and_tags`）。

#### M42-UI-02 微缩图集圆角

- **来源**：`13` §7 P-M41-04 / §8 / §10.3。**优先级 P0**。
- **场景**：默认 96px 档已圆角；缩到 ≤48px 档时走图集子矩形，`frame_radius=0` 仍是直角，与其余档割裂。
- **交互与状态**：`≤48px` 档（`draw_from_atlas`）子矩形按 8px 圆角裁剪；三布局四角一致；从大档缩到小档过渡不闪、不错位。
- **验收标准（AC）**：
  - AC-01 缩到最小档，方格/纵瀑布/横瀑布四角均为 8px 圆角。
  - AC-02 图集子矩形裁剪不越界、不串入相邻格像素。
  - AC-03 `grid.rs` 既有布局单测（列宽 / 行高 / 文件名位置）不回退。
  - AC-04 圆角绘制不使网格滚动 p99 回退（R-M42-1）。
- **约束**：只改裁剪路径，不改 `CELL_GAP` / `GRID_PAD` / `LOG_STEPS`；不新增贴图上传。
- **落点**：`grid.rs:1133-1141` `draw_from_atlas`（§2.4）。
