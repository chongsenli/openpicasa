## 2. 目标与非目标

### 2.1 目标

1. 在不丢失现有实装能力的前提下，把主界面壳层改到已确认的 v1.4 信息架构与视觉。
2. 浏览页保持「看和管理照片」：三种实装布局、完整搜索 / 筛选 / 排序、框选、整理（收藏 / 说明 / 标签三态 / 相册 / 托盘），不把浏览页变成编辑台。
3. 查看器改为展厅结构：大图 + 说明条 + 胶片条 + 可开关的右侧「照片信息」栏；信息栏展开时**推动**主图与胶片条，不遮挡主图。连续缩放、并排比较、显示位置、载入句、静止隐藏 chrome 等实装能力全部保留。
4. 索引管理五标签、总览、失败五类、按条暂停与全局暂停区分、系统暂停禁止人工继续、根四态按钮、排除项恢复、存储诊断、索引包导入导出四步六态、危险范围与确认、>1.5 秒浮层与「索引进度」详情全部保留；只收拢入口，不删能力。
5. 原文件边界写清楚：只有「移到废纸篓」会移动原文件；其余组织标记与索引删除只写独立索引库，不向照片目录写辅助文件。
6. 未知总数只显示已处理张数和耗时，不造分母、百分比或 ETA。

### 2.2 非目标（默认 M5 不做，或不得声称已实现）

- 不移植 HeroUI Pro、beUI Pro 或其他 Web 组件库；只把视觉语言转译到 egui。
- 不以玻璃为主材质；不用白圆按钮群；不用 AI / 人物替代文件夹导航。
- 不做编辑工作台（旋转、裁剪、调色）。顶栏「编辑」保持「下一版开放」toast（XX-01 / TB-04）。
- 不做人物、颜色、云同步筛选或浏览替代。
- 下列原型演示扩展列为**候选 / 非目标**，不得当作既有实装，也不得写入默认 M5 验收通过条件：1–5 评分及按评分排序 / 筛选；列表布局；可播放幻灯片；「从相册移出」；用「最近导入」替代「最近更改」；「恢复演示数据」及设置页「演示与数据」审核开关。
- 不把不可达窗口做成能用功能：旧「诊断」窗、「重建失败索引」（含「约 N 秒」）、无调用点的状态栏按钮「索引进度」（IDX-10 / XX-03～05）。
- 不把索引审计第 10 节规划项补进默认范围，包括但不限于：导入 / 导出暂停与张/秒、强制重扫时选择「仅当前 / 含子树」、导入预览可展开树与按根 12 张、浏览导入后自动选中左栏、离线盘名字段（IDX-16）、备份自动轮换 / 定时备份、身份待匹配队列、全库一键重建（IDX-11）。
- 不把离线原型的演示 JSON / TXT 当作正式 `.opicasaidx` 数据库格式。产品导入导出仍使用审计中的 `opicasaidx` / `opicasaidx.zip`。
- 不把原型 97/97 自动化结果当作桌面回归已通过。
- Windows 上「移到废纸篓」按审计仍是「当前平台暂不支持」，本文件不擅自承诺补齐 Windows `SHFileOperationW`（若要做，须另开范围）。

## 3. 信息架构与导航

本章全部为**已确认提案（v1.4）**，用来覆盖与之冲突的更早入口，而不是删除设置页或索引管理的能力。

### 3.1 主窗口结构

参考截图：`designs/prototype-v1/shots-v1.4/v14-light-home.png`、`v14-dark-home.png`。设计参考视口 1280×820。

从上到下、从左到右：

1. 标题栏（macOS 三色交通灯 + 应用名；暗色标题可用小号大写 `OPENPICASA`，见视觉章）。
2. 顶栏：边栏显隐、**导入**、幻灯片（未接通）、编辑（未接通）、收藏、说明、标签、托盘、（可视的其它整理入口）、标题与副标题 / 面包屑、三种布局胶囊、搜索（含「文 / 全」）、排序、筛选、更多。**没有**缩略图 −/+。
3. 左侧栏 + 主网格。侧栏右缘可拖宽度。
4. 底栏：左侧为选择计数或只读运行状态（及进行中的 IO 短句）；中间弹性空白；**最右侧**为「缩略图」连续滑块 + 像素值。没有索引管理按钮、红角标或整区可点入口。

### 3.2 侧栏顺序（M5-IA-01）

固定顺序：

**图库 → 标签 → 相册 → 文件夹 → 导入的索引（仅当存在导入来源时，紧挨文件夹之后）→ 底部照片托盘。**

- 「图库」组内仍含：所有照片、最近更改、星标、年份行。原型里可见的「最近导入」是 C 扩展，产品默认不得用它替换「最近更改」；若临时保留入口，必须标明扩展且不可作为默认导航。
- 文件夹子树、右键、折叠、本层计数、索引状态点全部保留。
- **删除整个「设置」组及其「索引管理」子项**，不留空标题或孤立子项。不是删除设置页 / 索引管理页本身。

### 3.3 索引管理入口（M5-IA-02 / M5-IA-04 / M5-IDX-01）

| 位置 | M5 要求 | 相对当前产品（事实） |
| --- | --- | --- |
| 侧栏 | 无设置组、无索引子项 | 产品本就没有设置页；若后续壳曾加入该组，M5 也不放 |
| 底栏 | 去掉「索引管理」按钮、角标、可点区域（已确认，不再待定）。运行中「已处理 N 张 · 已用 mm:ss」以及 IO 短进度作为**不可点状态**放在左侧，或走原来的 >1.5 秒浮层；不得挤到滑块右侧，也不得把短进度重新做成入口。导入 / 导出改由更多菜单、设置或索引管理窗口到达 | 事实：按钮四态文案恒为「索引管理」，角标 + 三句悬停，IO pill 可点并切到「导入 / 导出」。该可点入口由 v1.4 覆盖，M5 不再保留 |
| 顶栏 | 不新增齿轮。导入按钮保留，用于添加关注文件夹 | 事实：导入与「… → 添加文件夹…」都走 `add_folder` |
| 更多菜单 | 去掉「添加文件夹…」。保留「设置…」（⌘,）和已有的「索引管理…」直达 | 事实：更多菜单第一项是「添加文件夹…」 |
| 设置页 | 作为 B 已确认的入口壳。页内有「打开索引管理」。设置里的「演示与数据」**不是**产品功能 | 事实：真实应用没有设置页 |
| 索引进度空态 | 仍可「添加关注文件夹」「删除索引」（全库，只删索引） | 保留 |
| 浮层「详情」 | 仍打开「索引进度」，从中仍可「打开索引管理」并按问题定位标签 | 保留 |

默认打开哪个标签的逻辑（事实，须保留）：有失败任务 →「任务」；否则有离线根 →「关注文件夹」；否则有失效排除项 →「排除项」；否则「任务」。不会默认打开导入页。

参考截图：`v14-light-more-menu.png`、`v14-dark-more-menu.png`、`v14-light-settings-to-index.png`。

### 3.4 空库指引（M5-SH-04）

空网格标题仍是「这里还没有照片」。第二行改为指向**顶栏导入按钮**，不得再写「点顶栏「…」→「添加文件夹…」」。左栏「还没有加入任何文件夹」同样改指引。产品当前文案是事实，M5 必须改，否则会指向已删除的菜单项。

### 3.5 更多菜单可见项（产品默认）

以 v1.4 菜单为壳，去掉 C 项后，产品默认应包含：包含子文件夹（仅文件夹视图可点）、显示文件名、设置…、索引管理…、关于 OpenPicasa；全屏若放在此菜单则与 MN-04 一致。可选待确认：帮助与快捷键页、主题切换入口。不得出现「添加文件夹…」。不得把「列表布局（演示扩展）」「恢复演示数据」作为默认产品项。

排序菜单仍在排序按钮下，不是用更多菜单替代 MN-06～08。

## 4. 逐项需求（壳、视觉、关键行为）

下面写 M5 要落地的关键需求。第 6 章矩阵对 165 个原始编号逐条追溯，两者一起构成完整范围。界面原文用「」。

### 4.1 启动与壳层

**M5-SH-01（事实，P0）** 启动即进入主窗口，无欢迎向导、无强制设置首页。恢复 preferences `last_view`（不强制恢复查看器）。若有上次未完成且非用户暂停 / 取消的索引任务，后台自动续跑，并 toast：「检测到 {n} 个上次未完成的索引任务，已自动续跑（暂停/取消的任务保持原状）」。

**M5-SH-02（事实，P0）** 主区标题按 `view_title()` 优先级：本次导入 > 标签 > 星标 > 所有照片 / 最近更改 / 文件夹名；无名文件夹为「未命名文件夹」。副标题为「{total} 张」或「{total} 张 · 拍摄时间：{起—止}」（单日可只显示一个日期）。只根据已加载照片计算跨度。

**M5-SH-03（事实，P0）** 非文件夹：面包屑单段「图库」，不可点。文件夹：`图库 / 祖先 / 当前`，祖先可点，悬停「转到「{名}」」，当前段不可点。

**M5-SH-05（事实，P0）** 搜索或筛选无结果：「没有符合条件的照片」 / 「当前搜索或筛选没有结果」，可清除筛选，不改口叫用户去添加文件夹。

**M5-SH-06（事实，P0）** 库错误用顶中可关闭红条显示 `last_error`。打开库失败可退到内存库并写日志。查看器内不叠这条红条，以免挡住原图。不把原型独立的「目录失联 / 权限失败」演示页当成产品路由；产品用索引状态与 toast 表达。

**M5-TB-01 / M5-SB-21（事实，P0）** 显示 / 隐藏边栏始终可点；宽度有最小最大值并写入 `sidebar_width`。显隐本身随会话。

### 4.2 缩略图尺寸（M5-TB-10 / M5-THUMB-01，提案已确认，P0）

- 去掉顶栏缩略图 −/+ 及其占位。布局切换等其它顶栏功能保留。
- 底栏最右侧：「缩略图」滑块 + 实时像素文案，成组贴右。
- 范围 **22–512 px**，**线性 step=1**，`input` 即刻改变网格边长，跨页面、跨刷新写入 preferences 并保持。亮色 / 暗色同一套范围与行为。
- 键盘与滑块共用同一状态：⌘− 或 ⌘1 小一档，⌘+ / ⌘= 或 ⌘2 大一档（步进 16，不是 96/192 预设），⌘0 回到 **96 px**。不改为对数步进。
- 查看器内的缩放 −/+ **保留**，与图库缩略图尺寸不是同一控件。
- 极小尺寸（约 22–64 px）收紧缩略图圆角，避免看起来像胶囊。
- 默认边长：产品事实默认 96，v1.4 原型默认 144。⌘0 在两种情况下都回到 96。默认取哪一个见第 11 章，不在此擅自定稿。

### 4.3 布局、搜索、筛选、排序

**M5-TB-09（事实，P0）** 工具栏三种实装布局：方格、纵向瀑布流、横向瀑布流（三连胶囊，无文字，选中态用主题强调色）。瀑布流不画日期分组头。列表布局若出现，只能作为明示的演示扩展，且**不是**默认 M5。

**M5-SF-01～16（事实，P0）** 搜索对文件名或文件夹路径做 LIKE，与当前筛选求交；范围「文」（当前文件夹）/「全」（全部图库）可切换；焦点在输入框时**整张快捷键表停用**（Esc 只失焦或关弹层，不离开查看器）。筛选含：只看收藏、完整类型列表（全部 / JPEG / PNG / GIF / WebP / TIFF / SVG / HEIC / AVIF / RAW，RAW 一次覆盖 cr2/cr3/nef/arw/dng）、长边三档尺寸、标签自由输入、相机 / 镜头（须点应用）、缺拍摄时间、缺元数据、文件大小 KB 上下界（须点应用）、清除全部筛选（不退出文件夹）。日期筛选的唯一 UI 是侧栏年份（XX-06：面板不得因此长出日期控件）。无评分 / 人物 / 颜色筛选。

**M5-MN-06～08 / M5-SF-13 / M5-GR-09（事实，P0）** 排序键：拍摄日期、文件名、修改日期、文件大小、图片尺寸；当前键前缀「✓」，降序再加「↓」；「改为升序 / 改为降序」；「有缩略图的排在前面」（没有缩略图的，含云端未下载、生成失败，集中排后）。无「评分」排序。日期分组头格式 `YYYY年MM月DD日`，仅当布局为方格且排序键为拍摄日期。

### 4.4 整理与网格

收藏、说明、标签三态、相册、托盘按第 6 章 OR / TB / SB 全表保留。要点：

- 收藏是布尔，不是 1–5 星；顶栏双态；无选中 toast「请先选择照片」，按钮不置灰；只写索引。
- 说明在独立窗口编辑，只写应用索引，多选不预填第一张，查看器内不编辑说明。

### 4.7 危险操作：必须拆开（P0）

**M5-FS-01（事实）** 「移到废纸篓？」是**唯一会移动原文件**的用户动作。实现是 `rename` 到系统回收站目录，不是取消索引链接。

- 正文：「将把 {n} 张照片移到系统废纸篓。」空行「可以在 Finder 的废纸篓里还原，我们不会直接删除文件。」
- 按钮：「取消」（默认焦点）、「移到废纸篓」。
- Unix 启动盘：`~/.Trash`。外接卷：`/Volumes/{卷}/.Trashes/{uid}`。
- 跨卷失败：「无法移动到回收站（跨卷）：{路径}。请在 Finder 中删除这张照片。」
- 文件不存在：「文件不存在：…」
- Windows：「当前平台暂不支持移到回收站（Windows 需要 SHFileOperationW）」，且不会把文件搬去假目录。
- 成功后从索引去掉该行，toast「已移到废纸篓 {ok} 张」或部分失败句。

上述「{n} 张」在图库与查看器中都必须等于即将被移动的文件集合大小。**审计事实：** 当前查看器实现会把确认张数写成 1，却可能移动整个 `selection`（见 VW-15）。**M5 修复（P0，非待定）：** 任何「移到废纸篓」确认的执行集合必须与用户已确认的张数完全一致；范围变化必须重新确认；取消或关闭确认框则不执行。该规则同样适用于其它写明张数或范围的危险确认（例如导入来源移除、单根 / 全库删索引）：确认正文中的范围与实际作用集合必须一致；数量未知时写「待计算」，不得用错误张数执行。

**M5-FS-02 / M5-IDX-06（事实）** 下列操作**不改、不移动、不重命名原片**，只动索引库或日志 / 导出目录（导出目录禁止落在照片根内）。组织标记（收藏、说明、标签、相册）只存在独立索引，不向照片目录写辅助文件：

1. 关注文件夹卡片「删除索引」：确认标题「确认删除索引」，确认钮「确认」。彻底删除该根索引、缩略图和管理页这一行，不能再「重新索引（恢复）」，要重新添加并扫描。标记按身份骨架保留。
2. 「索引进度」里的全库「删除索引」：确认标题「删除索引」，确认钮是「删除索引」不是「确认」。关注文件夹规则还在，重新扫描可挂回标记。
3. 左栏根右键「从图库移除（删索引，不删文件）」：**无确认框**。清索引但留下 roots 行，管理页出现「索引已移除」+「重新索引（恢复）」。
4. 导入来源「从导入的索引中移除…」：有确认，确认钮「移除」，默认焦点在「取消」，toast 写明张数且「原图未动」。
5. 「关闭关注文件夹（保留索引）」与子文件夹「关闭此文件夹（不再显示）」（进排除项）以及「仅从分组隐藏」，都不是删原文件，也不是上面三套删除。

禁止再用「从资料库移除」一类文案盖住废纸篓和只删索引。禁止笼统写「所有操作都不动原图」。

### 4.8 索引管理能力（事实，P0；入口见 3.3）

二次确认框（索引管理内）必须按审计第 4 节原文使用范围句。数量未知写「待计算」，不写 0。取消在左且默认焦点在取消。除全库「删除索引」确认钮写「删除索引」外，管理窗内确认钮为「确认」。导入来源移除确认钮为「移除」。左栏「从图库移除」没有确认框。

最容易漏的 12 条（索引审计第 11 节）全部纳入验收意识，并在 AC-IDX-* / AC-FS-* 中抽查：

1. 不要把运行状态写进已删除的底栏按钮文字；M5 底栏不再有该按钮。
2. 角标（若在管理窗小字中沿用同一公式）计的是「几件事」不是「几张失败照片」；悬停三句之和可能小于角标，因为监视降级只在关注文件夹顶部说明。
3. 短任务不弹浮层；失败或不可访问时浮层不自动消失。
4. 两套暂停：任务行 per task_id；索引进度底部是全局。`task_id == 0` 的行没有暂停 / 取消。
5. 三种删索引文案和确认按钮字不同；左栏移除无确认。
6. 离线 / 已关闭 / 索引已移除 / 正常，四套按钮不一样；离线根没有「全量重建」。
7. 「格式不支持」没有重试；忽略不是隐藏。
8. 没有 ETA。唯一带「约 N 秒」的框用户点不到，也不许做成能用。
9. 缩略图统计没回来时是「计算中…」，不是 0。
10. 关索引管理窗口、关浮层 ×，索引都继续。取消导入才回滚，并强调现有索引未改动。
11. 「在 Finder 中显示」在非 macOS 也仍显示这七个字（是否改写见待确认）。
12. 帧时间直方图勾选不要画成可用诊断图。

禁止沿用 v1.2 索引页或仓库 `m4.2-full-prototype.html` P11–P14 的错误文案（审计第 8–9 节）：任务行百分比、来源三态芯片「在线 / 失联 / 权限失败」、一个全局「暂停演示」、总览「N 项异常」、离线根「重新打开」、监视「已开启」、把「不修改原片」页脚画在所有标签底部、把「索引已移除」写成无法恢复却又画恢复按钮、把短于 1.5 秒的浮层画成常驻。

## 8. 异常与数据保护

1. **原文件：** 仅 FS-01 将文件 rename 到系统废纸篓。其余删除、关闭、排除、导入导出、整理标记都不移动原片。不能写「本应用从不改你的文件」或「只读不改原文件」这类全称承诺。准确表达是：独立索引上的组织动作（收藏、说明、标签、相册、只删索引等）不向照片目录写辅助文件、不移动原图；用户显式「移到废纸篓」会把原图移到系统废纸篓。关于入口必须符合这一含义，最终字句可待设计确认，但不得沿用现有误导句。
2. **标记存储：** 收藏、说明、标签、相册只写独立索引库，不在照片目录创建辅助文件（与用户显式把原图移到废纸篓相区别）。
3. **导出保护：** 诊断日志与索引包的目标目录若落在照片根内，必须拒绝（`check_export_dir`）。诊断 JSON 脱敏（路径哈希），界面不预览内容。
4. **导入事务：** 提交前中断或用户取消必须回滚，现有索引未改动。已提交的导入才进入结果页。关闭索引管理窗口不会取消导入；重开可继续看进度。
5. **权限与失联：** 添加文件夹失败不入库。离线根只能「连接后刷新」和「删除索引」。启动校验可以出现在悬停中，但不计入角标。
6. **平台：** Windows 废纸篓按审计仍提示暂不支持，且不得把文件搬进假目录（这是平台能力边界，不是确认范围错配）。Linux 打开目录仍走 dbus / 父目录；按钮字目前仍是 Finder，用词是否本地化见 §11，不因此放宽安全规则。
7. **选择与危险动作：** 无选中不弹废纸篓。确认张数必须与执行集合完全一致；范围变化须重新确认；取消不执行。**审计事实：** 当前查看器确认写 1、可能移动整个 `selection`，是缺陷。M5 按 AC-FS-CONFIRM 验收修复结果，不得再按该错配编写「保持现状」用例。
8. **不编造进度：** 未知总数禁止百分比与 ETA。缩略图占用未就绪禁止写 0。
9. **日志与 VACUUM：** 清空运行日志只影响声明路径上的日志文件，不影响索引库、任务历史、照片和已导出的诊断副本。VACUUM 立即执行，失败要有原文反馈。

4. **主题切换入口：** 亮暗视觉已确认。控件放在设置页、更多菜单，还是跟随系统另加手动覆盖，尚未定稿。
5. **「方格显示文件名」持久化：** 产品只在本会话有效。是否改为写入 preferences？
6. **去掉底栏角标后的注意力：** 失败任务、离线根、失效排除不再用底栏红角标。是否仅依赖浮层、只读状态和管理窗内小字，或另做**不可点、不恢复旧按钮**的提示？不得借此恢复底栏「索引管理」或可点 IO 入口。
7. **暗色相册缩略图卡：** 是否必须与亮色文字行保持这组主题差异？
8. **关于入口的最终字句：** 准确含义已在 M5-MN-05 / §8 规定（独立索引组织动作不写照片目录、不移动原图；显式废纸篓会移动原图）。最终用词可由设计确认，但不得再使用「只读不改原文件」或同等全称承诺。
9. **Linux 上的「Finder」用词：** 当前产品按钮字在非 macOS 仍是「在 Finder 中打开 / 显示」。是否本地化？这是用词问题，不是「保持现状以便沿用错误安全承诺」。
10. **设置页内容范围：** 作为入口壳（外观、打开索引管理、图库来源入口）已确认需要一个可达的设置表面。哪些段落进入产品？「演示与数据」明确不进入正式产品。
