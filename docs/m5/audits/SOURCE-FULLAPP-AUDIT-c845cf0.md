# OpenPicasa 已实现功能审计（全应用）

基线：远程默认分支 `main`，`c845cf0363eed237ef51be1ca379a4aec4cbe446`，版本 `0.4.2-beta.1`。工作区干净，与 `origin/main` 相同。本次未改仓库、未建 PR、未做原型、未对任何照片目录做扫描或删除。

**核验方式：源码核对，没有运行桌面程序，没有目视验证。** 环境仍无预编译二进制；打开具体窗口没有专用环境变量。索引管理的逐字清单仍以 [index-management-audit.md](SOURCE-INDEX-AUDIT-c845cf0.md) 为准，本文件第 12 节只复核入口有没有漏，不重复每一句确认文案。

永久链接前缀：

`https://github.com/chongsenli/openpicasa/blob/c845cf0363eed237ef51be1ca379a4aec4cbe446/`

分档：

| 档 | 含义 |
| --- | --- |
| 已实现 | 有点击或按键能走到，并且处理函数真的被调用 |
| 可见未接通 | 控件画出来了，点击只吐说明或改一个没人读的状态 |
| 不可达 | 绘制函数还在，没有任何赋值或调用能打开它 |
| 文档规划 | `docs/` 写了，源码界面没有对应控件 |

对照列针对附件原型 v1.2（`#/` 路由的独立 HTML，不是本仓库）。「有」= 原型有相近入口；「缺」= 没有；「偏差」= 有，但文案、范围或是否改原文件不一致。

持久化位置：`preferences.json`（视图、缩放、排序、侧栏、托盘、标签排序等）、SQLite 索引库（照片行、星标、说明、标签、相册、根、排除、任务）、`settings` 表（递归浏览、索引移除标记、导入导出重启标记）。星标/说明/标签/相册只写索引库。

## 14. 与 v1.2 的差异，以及建议先补的顺序

v1.2 已有、且和产品大方向一致、可以留着再对文案的：侧栏显隐、搜索、方格浏览、单击 / ⌘ 单击 / Shift 范围、双击进查看器、星标布尔、标签、相册、托盘、空结果文案、加载中文案、信息面板开关、清除筛选。

v1.2 **多出来、产品没做、不要当成已实现**的：

1. 设置页，以及 `#/settings/index` 这种「索引是设置的子页」。
2. 1–5 评分、数字键打分、按评分排序或筛选。
3. 照片上的批量条「从资料库移除」「从相册移出」。
4. 底片条、适合/100%/200% 三档、列表布局、80–280 连续滑块。
5. 帮助页和 ⌘,、?。
6. 「最近导入」作为和「最近更改」不同的固定视图（产品的「最近更改」是另一查询；「本次导入」是导入成功后的临时标题）。
7. 演示向导、恢复演示数据、目录失联/权限失败独立路由。
8. 可播放的幻灯片（产品按钮是占位 toast）。

建议按这个顺序补进原型，避免再漏「已经做了的」：

1. **危险动作拆开。** 废纸篓会移动原文件（FS-01）。只删索引的按钮保持现在的三套文案（IDX-06）。不要用一个「从资料库移除」盖住两者。
2. **索引五标签和两套进度**（IDX-01～09）。v1.2 索引页现在只有一条百分比、来源状态和全局暂停/重建。
3. **顶栏真实控件**：三种布局、−/+（22–512）、对象四按钮（收藏双态、说明窗、标签三态、托盘双态）、搜索范围「文/全」。
4. **侧栏真实行**：所有照片、最近更改、星标、年份、文件夹右键四则、导入的索引、标签排序与空标签、相册右键、托盘清空和右键移出。
5. **筛选面板里真正有的项**（SF-04～SF-11），删掉评分。日期只做年份，除非以后源码加了区间。
6. **查看器**：返回、显示位置、百分比缩放、并排比较、信息字段和「该文件没有 EXIF 信息」、无胶片条、只读星标和标签。
7. **快捷键表改成第 9 节**，去掉评分和设置/帮助键，补上反选、含子文件夹、显示位置、并排比较。
8. **空态文案**改成 SH-04 那两句，入口写成顶栏「… → 添加文件夹…」。
9. 占位格「待生成 / 失败」，云端未下载保持无字。
10. 幻灯片和编辑若保留按钮，悬停和点击都要是「下一版开放」，不要做成能播的功能。

框选（GR-03）产品已实现，v1.2 自己声明没做。它比「再画一个设置页」更接近现有软件，但优先级低于危险动作和索引页。
