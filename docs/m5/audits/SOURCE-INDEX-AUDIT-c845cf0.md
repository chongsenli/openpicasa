## 1. 用户能走到的表面（没有「设置 → 索引」页）

真实应用没有设置页，也没有 `#/settings/index` 路由。索引相关界面是这些：

1. **底栏右侧按钮「索引管理」** → 非模态窗口「索引管理」（五个标签）。`statusbar.rs` 文件头把旧「索引进度」「诊断」和工具栏二级菜单标成已移除。`diag_clicked` 被写成恒 `false`（`statusbar.rs` L111），所以旧「诊断」窗口画了也打不开。
2. **底栏进度 pill**（只在导入/导出进行中或准备中出现）→ 同一窗口并切到「导入 / 导出」。
3. **右下角浮层「正在建立缩略图索引」**（任务持续超过 1.5 秒才出现）→「详情」打开「索引进度」窗口。这是第二套进度 UI，和索引管理窗口并存。
4. **顶栏「导入」和「… → 添加文件夹…」** → 系统选文件夹，然后开始索引。
5. **左栏「文件夹」树** 右键，以及有导入来源时才出现的 **「导入的索引」** 分组右键。
6. 栅格占位格「待生成」「失败」（云端未下载是静默灰格，不写字）。

工具栏没有「索引管理」菜单。排序、筛选、搜索是图库浏览控件，不是索引管理页里的控件。

## 2. 底栏入口

源码：`crates/picasa-ui/src/statusbar.rs` L179–L259；状态机 `crates/picasa-core/src/mgmt.rs` L498–L538。

按钮文案**四种状态都是「索引管理」**，只改颜色和图标，不改字。右键没有菜单。按钮宽 104px。

| 状态 | 条件（互斥，失败优先） | 可见表现 |
| --- | --- | --- |
| 空闲 `Idle` | 角标 0、非系统暂停、没有运行中任务 | 普通字色，无环、无角标 |
| 进行中 `Running` | 有 `running` 任务且角标为 0 | 进度色 + 左侧旋转小环。**不显示百分比数字** |
| 系统暂停 `Paused` | `paused_by_system` 且角标为 0 | 警告色。没有「继续」 |
| 需要处理 `Attention` | `badge > 0` | 危险色 + 红底白字角标。≥100 显示 `99+` |

角标公式（`mgmt.rs` L417–L430）：未忽略失败的**任务数**（不是照片张数）+ 路径已失效的排除项数 + 在线判定为离线且未关闭的根数 + 监视降级的在线根数。

悬停（`badge_tooltip`，`mgmt.rs` L445–L458）只拼非零的这三句，**监视降级不进悬停**：

- `{n} 个任务有失败项`
- `{n} 条排除项已失效`
- `{n} 个根目录离线`

启动校验进行时，悬停末尾另起一行：`启动校验：{快筛|全校}：已检查 {N} 目录 / {M} 文件`（`verify.rs` L211–L216，`statusbar.rs` L251–L256）。校验不进角标。

点击：先刷新快照，再 `open_at`。默认标签（`mgmt.rs` L465–L475）：有失败任务 →「任务」；否则有离线根 →「关注文件夹」；否则有失效排除项 →「排除项」；否则「任务」。不会默认打开导入页。

### 导入/导出 pill（IDX-18，能用）

`statusbar.rs` L113–L162。仅当 `IoState` 为「进行中」或「准备中」时画在「索引管理」左侧。宽 210，底边 4px 进度条。

短文案（`index_mgr.rs` `progress_short_label` L460–L464）：

- 总数已知：`{阶段} · {done} / {total}`
- 总数未知：`{阶段} · 已处理 {done}`，条用 0.3 宽度循环，不编百分比

悬停：`点击查看导入 / 导出进度详情`。点击打开索引管理并强制切到「导入 / 导出」（`app.rs` L2889–L2896）。空闲、成功、失败、取消时 pill **消失**。没有 ETA。

## 3. 窗口「索引管理」

`index_mgr.rs` `show` L769–L854。

- 标题：`索引管理`
- 非模态。关掉窗口**不取消**后台索引或导入导出。
- 可缩放。默认 760×560，最小 560×380。
- 关窗口时清掉还没确认的二次确认框。
- 内容在垂直滚动区里，滚动 id `index-mgr-scroll`。

五个标签，文案来自 `MgmtTab::label`（`mgmt.rs` L328–L335），从左到右：

`任务` · `关注文件夹` · `排除项` · `存储与诊断` · `导入 / 导出`

角标 > 0 时，标签行右侧常驻一行小字，内容与底栏悬停相同（同样不含监视降级）。监视降级的说明在「关注文件夹」标签顶部另有一行。

### 3.1 总览（五个标签之上常驻）

`overview_summary`，`index_mgr.rs` L1290–L1352。不是表格，是几行标签+值。

| 标签 | 值 |
| --- | --- |
| `图库根目录` | 空库：`尚未添加图库根目录`（警告色）。否则每个根一行 `root_summary_line`：`{正常\|已关闭\|离线\|索引已移除} · {N} 张`，有缩略图再加 ` · 缩略图 {字节}`，失败 > 0 再加 ` · 失败 {M}`。离线根用警告色。字节：`{n} B` / `{n} KB` / `{n.n} MB` / `{n.nn} GB`（1024 进制） |
| `索引状态` | `● {最近一条 running 任务的状态文案}`；没有运行中任务则 `● 空闲` |
| `照片数量` | `{all_photos} 张`（只数未关闭根，含失败与离线，不含已关闭子目录） |
| `最近更新` | 根的 `last_indexed_at` 与任务 `started_at` 取最大，再走相对时间。都没有：`尚未索引` |
| 异常行 | 仅 `badge > 0` 时出现 `⚠` + 同上悬停三句。为 0 时整行不画，不写「一切正常」 |

相对时间（`index_mgr.rs` L631–L649）：无时间戳 `从未`；未来 `刚刚`；&lt;60 秒 `刚刚`；&lt;1 小时 `{n} 分钟前`；&lt;1 天 `{n} 小时前`；&lt;30 天 `{n} 天前`；否则 `30 天前以上`。

任务状态字（与进度浮层共用 `IndexState::label`，`index.rs` L58–L66）：`等待` `扫描中` `生成缩略图中` `已完成` `部分失败` `暂停` `不可访问`。

任务类型字（`TaskKind::label`，`schema.rs` L657–L665）：`首次索引` `刷新` `重建` `恢复` `回填尺寸` `校验`。

### 3.2 标签「任务」

`tasks_tab`，`index_mgr.rs` L857–L981。**没有表头、没有排序、没有筛选、没有勾选、没有目录树。** 每条任务是一行横排文字。

#### 失败分类（永远在最上面）

小标题 `失败分类`。五类固定顺序（`FailureKind::label`，`types.rs` L357–L364）：

`无权限` · `文件损坏` · `目录失联` · `格式不支持` · `超时`

某类 `count + ignored == 0` 则整行不画。有数据时一行：

- 类名（加粗）
- `{count} 条`
- 若 ignored &gt; 0：`已忽略 {n}（仍可见）`
- 可重试且 count &gt; 0：按钮 `重试全部`。`格式不支持` 不给按钮，改为灰色字 `不支持重试`
- count &gt; 0：按钮 `忽略全部`
- ignored &gt; 0：按钮 `取消忽略`

五类全空：`没有失败项`。

这里**不列出单张文件名**。单张失败列表在「索引进度」浮层的「查看失败项」里，不在本标签。

反馈：

- 重试：`已重新入队 {n} 张（{类名}）`；没有 id 时 `没有可重试的「{类名}」项`
- 忽略/取消：`已忽略 {k} 条「{类名}」失败项（列表仍然可见）` 或 `已取消忽略 …`；失败 `操作失败`

#### 任务列表

小标题 `任务`。

按钮 `清空任务历史…`。没有已结束记录时 **禁用**，旁边灰字 `没有已结束的任务记录`。悬停：`删除任务页里已结束的记录与失败明细；正在跑的任务不受影响`。点击先弹确认，不直接删。

列表空：`暂无索引任务`（然后本标签其余内容不画，包括系统暂停那一行——因为函数在这里 return）。

有任务时，进行中的排前面，历史在后。历史最多 50 条（`HISTORY_KEEP = 50`，`mgmt.rs` L38）。**同一条不会既在进行中又在历史里。** 一行从左到右：

1. 范围路径（加粗）`t.scope`
2. 类型文案
3. 状态文案
4. 进行中：`已处理 {discovered} 张 · 已用 {mm:ss}`。**没有百分比、没有 ETA、没有进度条**
5. 终态另加结局字：`成功` / `部分失败` / `失败` / `已取消`（`TaskOutcome::label`）
6. 终态再加：`完成 {completed} · 跳过 {skipped} · 失败 {failed}`，若有取消原因再加 ` · 已取消（{reason}）`

进行中且 `task_id != 0`：

- 用户暂停：警告色 `已暂停` + 按钮 `继续` + 按钮 `取消`
- 否则：按钮 `暂停` + 按钮 `取消`
- `task_id == 0`（还没对齐到库里的会话任务）：**不画**暂停/继续/取消

反馈：

- `该索引任务已暂停（其它任务不受影响）`
- `该索引任务已继续（从检查点续跑）`
- `该索引任务已取消（已建索引与用户标记保留）`（取消原因写入 `用户取消`）

系统暂停且列表非空时，列表下方警告色一行，**没有继续按钮**：

`系统暂停中（休眠 / 低电量），恢复由系统事件自动发生`

启动时若有未完成任务（`app.rs` L522–L524）：

`检测到 {n} 个上次未完成的索引任务，已自动续跑（暂停/取消的任务保持原状）`

### 3.3 标签「关注文件夹」

`folders_tab`，`index_mgr.rs` L984–L1130。每个根是一个 `ui.group` 卡片，**不是可展开的目录树**。子目录不在这里列。没有搜索、排序、多选。

空：`还没有关注任何文件夹`。

监视降级 &gt; 0 时顶部警告：

`{n} 个文件夹的实时监视不可用，已改为定时检查（详情见各行的「为什么？」）`

每张卡片：

- 路径（加粗）+ 状态字。颜色：离线危险色，索引已移除警告色，已关闭灰色，正常成功色。
- 摘要行（同总览的 `root_summary_line`）
- `最近索引：{相对时间}`

状态字（`RootView::status_text`，离线优先于已关闭，`mgmt.rs` L182–L192）：`离线` / `索引已移除` / `已关闭` / `正常`。

#### 状态「索引已移除」（仍能画到）

这条不是死分支。左栏「从图库移除（删索引，不删文件）」走 `clear_index_for_root`，**留下 roots 行**并打 `m43_index_removed_{id}`（`library.rs` L1384–L1399）。索引管理里的「删除索引」则是彻底删行，删完这张卡片消失。两种删除不是同一个按钮。

该状态下卡片正文：

`索引已移除：只有收藏 / 标签 / 说明 / 相册这些用户标记还在，重新索引会按身份自动挂回；原图与磁盘文件从未被动过。`

按钮只有三个：`重新索引（恢复）` · `在 Finder 中显示` · `删除索引`。不画监视行，也不画刷新/强制重扫/全量重建/关闭。

`重新索引（恢复）` 反馈：`正在重新索引「{path}」（用户标记会按身份自动挂回）`。

#### 其他状态的按钮

监视行永远画（已移除除外）：标签 `监视` + 状态字。

监视文案（`WatchState::label`，`watcher.rs` L164–L173）：

- `实时`
- `每 {分钟} 分钟检查 · {原因}`，原因：`网络卷` / `监视句柄不足` / `权限不足` / `监视器错误` / `已关闭`
- `事件过多，等待全量刷新`
- `未监视`（离线、已关闭、还没装上监视，都显示这个，不假装实时）

降级时多一个可悬停的 `为什么？`（不是按钮，是带 tooltip 的文字）。悬停正文：

- 网络卷：`网络卷（SMB / AFP / NFS）通常不支持文件系统事件，软件会按固定间隔检查。想要实时生效，可以把照片拷到本地磁盘再关注。`
- inotify：`该目录树需要 {need} 个监视句柄，当前上限 {have}。可以在系统层面调高（软件不会自动修改系统设置）：` 换行 `sudo sysctl fs.inotify.max_user_watches={建议值}`
- 权限：`没有读取该目录的权限。请在「系统设置 → 隐私与安全性 → 完全磁盘访问」里授权。`
- 后端错误：`监视器启动失败：{e}。已退回定时检查。`
- 事件过多：`短时间内有太多文件变化，已改为一次性重新检查这个文件夹。完成后会自动恢复实时监视。`

离线根按钮只有：`连接后刷新` 和 `删除索引`。没有重新索引、强制重扫、全量重建、关闭、重新打开、在 Finder 中显示。

在线根按钮，从左到右：

| 按钮 | 确认？ | 作用范围与反馈 |
| --- | --- | --- |
| `刷新` | 否 | 与 `重新索引` 走同一函数 `reindex_root`：对该根 `enqueue_refresh`。已移除的才会有上面那句恢复 toast；普通刷新没有专属 toast |
| `重新索引` | 否 | 同上 |
| `强制重扫` | 否 | 只对该根路径做跳过 L1 的文件级核对，不是子目录勾选。toast：`已对 {path} 开始强制重扫（跳过快筛，文件级核对）`。已有校验在跑：`已有校验任务在运行，请稍候` |
| `全量重建` | **是** | 先弹「确认全量重建」。确认后：`已对 {root} 开始全量重建（旧缩略图保留直到替换）`。旧缩略图留到被替换，不先清空 |
| `重新打开` 或 `关闭` | 否 | 已关闭显示「重新打开」，否则「关闭」。索引管理里这两下**没有 toast**（左栏右键的关闭才有 toast） |
| `在 Finder 中显示` | 否 | 按钮字在 Linux 上仍是 Finder。文件不存在：`文件不存在：{path}` |
| `删除索引` | **是** | 任何状态都可点（活跃/关闭/离线/已移除）。悬停：`彻底删除该根的索引与缩略图，并从索引管理里移除这一行（原图不动、不能撤销）`。确认后彻底删 `roots` 行。toast：`已彻底删除「{root}」的索引（索引数据与缩略图已删除，原图未动）`；根已不在：`该索引已经不存在`；连点：`已有删除任务在跑，请稍候` |

### 3.4 标签「排除项」

`exclusions_tab`，`index_mgr.rs` L1133–L1161。扁平路径列表，不是树，没有勾选。

空：`没有已关闭的子目录`（此时不画按钮）。

有项时：

- 按钮 `全部恢复`：对当前列表每一条发恢复，没有二次确认。
- `清理失效项`：没有失效项时画一个**禁用**按钮。有失效项时源码会画**两个**同名按钮（L1146 的 `add_enabled` 不读点击，L1147 再画一个能点的）。这是现实现状，原型若只放一个可用按钮，更接近用户预期，但和源码像素不一致。
- 每行：完整路径；路径不存在则警告色 `已失效`；按钮 `恢复`。

反馈：`已恢复 {路径}` / `恢复失败：{e}` / `已清理 {n} 条失效排除项`。

## 5. 右下角「正在建立缩略图索引」和窗口「索引进度」

### 5.1 浮层出现规则（能用）

`APPEAR_AFTER = 1.5` 秒，`HIDE_AFTER = 1.0` 秒（`index_progress.rs` L31–L35）。

- 新批次开始后 1.5 秒仍在跑，才出现。1.5 秒内结束的任务不出现。
- 正常结束：1 秒内收起。
- 有失败、有不可访问、或处于系统暂停：不自动收起。
- 用户点 `×` 后，这个批次不再弹出。悬停：`关闭（索引会继续）`。
- 锚在右下，避开状态栏。宽约 300。标题固定 `正在建立缩略图索引`，不随阶段改标题。

控件：

- `收起` / `收起后` 的 `展开`
- 收起时一行：`{阶段} · {done} / {found}`
- 展开：当前文件夹名（最多约 16 字）+ 阶段 + 从第 2 批起 `第 {n} 批`（第 1 批不写）
- 进度条：有百分比才按比例，没有就不确定动画。条上不印 ETA
- `已完成 {done} / 已发现 {found}` 或分母未知时 `已发现 {found} 张`；失败 &gt; 0 加 ` · 失败 {n} 项`
- 按钮 `详情`（打开「索引进度」，浮层本身的点击不返回别的动作）
- 不可访问：`有目录不可访问，请检查外接盘或权限`
- 否则有失败：`部分失败 {n} 项，索引未完全成功`

阶段汇总优先级（`index.rs` `stage_label`）：暂停 &gt; 生成缩略图中 &gt; 扫描中 &gt; 等待 &gt; 部分失败 &gt; 不可访问 &gt; 已完成。

| `删除索引` | 无边框、警告色。悬停：`删除照片索引与缩略图，关注文件夹保留`。打开下面的全库确认 |
| `关闭` | 只关本窗口 |

重试没有可重试项：`没有可重试的失败项`。目录还没入库：`目录尚未入库，无法重试`。

相对时间在这个面板是另一套函数（`index_progress.rs` `relative_time`）：`刚刚` / `{n} 秒前` / `{n} 分钟前` / `{n} 小时前` 这一类，悬停给绝对时间。和索引管理页的粗粒度「N 分钟前 / 30 天前以上」不是同一函数。

### 5.3 全库确认「删除索引」（能用，但只有索引进度面板能打开）

`draw_delete_index_confirm`，`app.rs` L4401–L4456。标题 `删除索引`，宽 360。

正文：

`范围：全库（所有关注文件夹）。将删除已建立的照片索引与缩略图。` 换行 `照片数：{all_photos} 张（全库）`

以及：原图与磁盘文件不删；关注文件夹和「关闭此文件夹」规则保留；收藏/标签/说明/相册保留，重新扫描后挂回。

按钮：`取消`（默认焦点）和 `删除索引`（不是「确认」）。Escape 取消。

执行 toast：`开始删除索引…` 或 `已在删除中，请稍候`。

这和关注文件夹卡片上的「删除索引」不是一回事：卡片那个确认标题是「确认删除索引」，只删一个根，并且把管理页里的那一行也删掉。

### 5.4 进不去的「重建失败索引」

`draw_rebuild_failed_confirm`（`app.rs` L4566）标题 `重建失败索引`，按钮 `开始重建` / `取消`，正文含估算耗时（`约 N 秒` / `约 N 分钟`）和「期间可以用「暂停索引」随时中止」。`confirm_rebuild_failed` 在整个仓库里只会被设成 `None`，没有任何赋值把它变成 `Some`。**用户现在点不到这个框。** 不要把它画进「现有能用功能」。失败重试的活入口是任务页「重试全部」和索引进度里的「重试失败项 / 全部重试」。

### 5.5 进不去的窗口「诊断」

`diagnostics.rs` `show`，标题 `诊断`。`statusbar` 的 `diag_clicked` 恒为 false，没有别的赋值把 `diagnostics_open` 设为 true。窗口内容（缓存占用、`清理缩略图`、`VACUUM 回收`、`全量重建…` / `确认重建？`、失败记录、`已关闭的文件夹`、`重新添加`、`刷新统计`、展示性能基准）与索引管理「存储与诊断」「排除项」重叠，但**当前没有入口**。左栏 toast 仍提到「可在诊断里恢复」，属于文案过时。

诊断页里全库重建的悬停句（若将来接回入口才可见）：`对全部关注文件夹做全量重建（逐张强制重新探测）；旧缩略图保留到被新图替换，原图文件与收藏 / 标签 / 说明 / 相册等用户标记不受影响。耗时较长，默认取消。` 确认按钮字是 `确认重建？`，取消 toast 不会出现，因为进不去。索引管理里对应的是**每个根**的「全量重建」，没有「全部根一起重建」的按钮。

## 6. 添加文件夹（索引入口，能用）

两处同一条 `add_folder`（`app.rs` L4717）：顶栏导入图标（tooltip 语义是添加关注文件夹，`topbar.rs` L36），以及「…」菜单第一项 `添加文件夹…`（`topbar.rs` L847）。索引进度空态的 `添加关注文件夹` 也进这里。

系统选文件夹标题：`选择照片文件夹（只读，不会修改你的文件）`。没选到：macOS toast `已取消选择文件夹`；其他平台 `未选择文件夹：已取消，或系统文件夹选择器未能弹出`。

读不了就不入库，toast 是原因加系统错误：

- `没有读取权限（系统设置 → 隐私与安全性 → 文件与文件夹）：{err}`
- `目录不存在，或所在磁盘没有挂载：{err}`
- `无法读取该目录：{err}`

同路径再加：`这个文件夹已经在图库里，正在重新索引`（不插第二行，但会再扫一次）。

父子重叠仍允许添加，只提示：

- 新目录包住已有根：`已添加；它包含 {n} 个已关注的文件夹，照片不会重复计数`
- 新目录落在已有根里面：`已添加；它的照片本来也在关注范围内，不会重复计数`

读树失败：`无法读取该目录`。

「…」菜单其余项与索引无关，但添加文件夹旁边有一条会影响**浏览范围**、容易被当成索引选项的项：`含子文件夹` / 勾选态 `✓ 只看本文件夹`（当前文件夹视图才可点）。它不改变扫描是否递归。

环境变量 `OPENPICASA_NO_STARTUP_SCAN=1` 会 toast `诊断模式：本次启动未扫描磁盘（OPENPICASA_NO_STARTUP_SCAN=1）`。这不是界面上的开关。

## 7. 左栏目录与来源（和索引管理配套，不在那个窗口里）

### 7.1 「文件夹」树

`sidebar.rs`。分组标题 `文件夹`，整行点击折叠。行：文件夹图标、名称、右侧本层张数（0 不显示）、有对应索引任务时右侧状态点。

状态点没有文字，颜色跟七态走；已完成是空心环；暂停是短横条不是圆点。悬停：

`{状态}：{名称} · 已完成 {c} / 已发现 {d}`

左键选中该文件夹。右键菜单（`app.rs` L3711–L3821），最小宽 200，点外面关闭：

| 项 | 谁能看到 | 结果 |
| --- | --- | --- |
| `在 Finder 中打开` | 所有文件夹行 | 打开目录 |
| `刷新此文件夹` | 所有 | `已加入刷新队列` 或 `这个文件夹正在索引，已合并` |
| `关闭关注文件夹（保留索引）` | 仅根 | toast `已关闭，重新添加同一目录可秒开`。索引留着，管理页状态变「已关闭」，按钮变「重新打开」 |
| `从图库移除（删索引，不删文件）` | 仅根 | **没有二次确认**。清这个根的索引但留下 roots 行 → 管理页出现「索引已移除」+「重新索引（恢复）」 |
| `关闭此文件夹（不再显示）` | 仅子文件夹 | 加排除并删该子树索引。toast `已关闭。可在「诊断」里恢复`（实际恢复在「排除项」） |

树的计数默认是**本层**张数，不是含子目录的总数。没有在索引界面里切换这个口径的控件。

### 7.2 「导入的索引」（有来源才出现）

分组标题就叫 `导入的索引`，在「文件夹」和「标签」之间，可折叠。本机根不进这组，导入根不进「文件夹」，避免一棵树画两次。

来源节点：导入图标、名称、右侧照片数（0 不显示）。悬停：

- `导入时间：{已格式化时间}`
- 离线再加 `离线：导出时的原路径当前不可读`
- `原路径：{用顿号拼接}`
- `右键可从导入的索引中移除（不碰原文件）`

来源下的文件夹行若属于导入：悬停可能是 `来自导入的索引` 或 `离线（导出时的原路径当前不可读）`，加上原路径、`导出时计数：{n}`。与本机同路径：`本机已有同名路径，以本机为准（计数只算一份）`。离线行文字变灰，图标上用关闭形角标；在线用导入角标。

来源节点右键（`app.rs` L3934–L4006）：

- 灰字标题 `「{名称}」`，缺名时用 `导入的索引`
- `仅从分组隐藏` → toast `已从「导入的索引」分组隐藏（可随时恢复）`。恢复按钮在导入/导出标签，不在左栏
- 分隔线
- `从导入的索引中移除…`
- 说明：`只删索引与缩略图；收藏/标签/说明/相册保留，原图不动`

确认窗标题 `从导入的索引中移除`，宽 420。正文：

`范围：导入来源「{name}」下的全部文件夹。` 换行 `照片数：{photos} 张`

有路径则 `原路径：{顿号拼接}`。然后说明只删这组索引与缩略图，不删不建原文件，标记保留。按钮 `取消`（默认焦点）和 `移除`。

成功 toast：`已移除导入的索引：{photos} 张照片、{thumbs} 张缩略图（原图未动）`。失败：`移除导入的索引失败：{e}`。

### 7.3 栅格上的索引状态（浏览时能看见）

占位格（`index_progress.rs` L864–L869）：`待生成`、`失败`（失败有警示色和右上角感叹号）。`CloudOnly` 只画灰格，**不写**「云端未下载」。

## 8. 对照附件原型 v1.2（`#/settings/index`）

v1.2 索引页实际只有这些（`js/app.js` `renderIndexManager`，约 L833–L862）：

- 面包屑 `返回设置 / 索引管理`，标题 `索引管理`，说明这是设置的下级、演示数据、不写原文件
- 一节 `当前任务`：一个任务名、状态芯片（`索引空闲` / `正在索引` / `已暂停` / `索引完成`）、类型后缀 `导入任务` 或 `重建任务`、一条百分比进度（`done / total（pct%）`）、一句 note
- 进行中才有 `暂停演示`；暂停后才有 `继续索引`；始终有 `重建索引（演示）`。暂停/继续是**全局一个** `indexJob`，不是按任务
- 一节 `图库来源`：名称、路径、`{n} 张已索引`、状态 `在线` / `失联` / `权限失败`，以及 `添加受监控文件夹…`
- 底栏索引进度整块可点，进的是这同一页

对照后，v1.2 **有、但和真实产品不是同一套字或同一套范围**的：

| v1.2 | 真实应用 |
| --- | --- |
| 设置的子页面，有「返回设置」 | 没有设置页。入口是底栏「索引管理」，外加导入时的 pill、以及索引进度浮层的「详情」 |
| 底栏状态会写成「正在索引 / 已暂停 / 索引完成」 | 底栏四个字永远是「索引管理」，状态靠颜色、转圈、角标 |
| 一个全局任务 + 百分比 + ETA 式的 done/total | 任务页多行，进行中是「已处理 N 张 · 已用 mm:ss」，明确不要 ETA。百分比只出现在导入/导出 |
| `暂停演示` / `继续索引` / `重建索引（演示）` 三个全局钮 | 暂停/继续/取消是**每一条持久任务**自己的按钮。全量重建是每个根一张卡片上的按钮，还要确认框。另有索引进度面板里的全局「暂停索引 / 继续索引」 |
| 来源三态：在线 / 失联 / 权限失败 | 根状态是 `正常` / `已关闭` / `离线` / `索引已移除`。权限是失败分类「无权限」和添加时的 toast，不是来源芯片 |
| `添加受监控文件夹…` 在索引页上 | 真实的添加在顶栏导入和「… → 添加文件夹…」，索引进度空态才叫 `添加关注文件夹` |

v1.2 **完全没有、后续原型要补的能用功能**：

1. 五标签，而不是一页进度。总览四字段：图库根目录、索引状态、照片数量、最近更新，外加异常行。
2. 失败分类五行：无权限、文件损坏、目录失联、格式不支持（只显示「不支持重试」）、超时。动作是「重试全部 / 忽略全部 / 取消忽略」，忽略后仍可见。
3. 任务行的类型、七态、结束摘要 `完成 · 跳过 · 失败 · 已取消（原因）`，以及「清空任务历史…」。
4. 系统暂停只说明、不给继续按钮。
5. 关注文件夹卡片：监视行（实时 / 每 N 分钟检查 · 原因 / 未监视 / 事件过多）、`为什么？`、最近索引相对时间。
6. 按根状态切换的按钮：刷新、重新索引、强制重扫、全量重建、关闭/重新打开、在 Finder 中显示、连接后刷新、重新索引（恢复）、删除索引。离线根不能看到全套按钮。
7. 两套删除必须分开画：单根「确认删除索引」（彻底、不可恢复）和索引进度里的全库「删除索引」（关注文件夹还在）。左栏「从图库移除」没有确认框，之后管理页会留下「索引已移除」。
8. 排除项：全部恢复、清理失效项、单条恢复、`已失效`。
9. 存储与诊断：库文件、WAL、缩略图（含「计算中…」）、按根分布、清理缩略图、VACUUM、清空运行日志、导出诊断日志。帧时间复选框若照实保留，应标成「点了没有直方图」。
10. 导入/导出整页：含缩略图勾选、导出、最近备份与 SHA-256、四步向导、合并/替换、`我已了解上述影响范围`、取消校验/取消导入、结果四计数、失败明细、浏览导入的照片、重新匹配、六态操作状态、中断后的重来/忽略/知道了、隐藏来源的恢复。
11. 底栏角标 `99+` 和三句悬停；导入进行中的 210px pill。
12. 右下角浮层（1.5 秒才出现、短任务不出现、失败不自动消失）以及「索引进度」里的按文件夹进度、查看失败项、重试失败项、全部重试、打开索引管理。
13. 左栏文件夹右键四到五个动作，和「导入的索引」右键「仅从分组隐藏 / 从导入的索引中移除…」。
14. 添加文件夹时的重复、父子重叠、无权限三句 toast。
15. 栅格「待生成」「失败」。云端未下载不要写成一行字。

v1.2 若继续用「一个重建按钮 + 一个暂停按钮」代替上面 6 和 7，就会把用户点名要留的功能弄丢。

`docs/prototypes/m4.2-full-prototype.html` 的标签名和窗口尺寸（760×560）与源码一致，但下面这些**不要**当成实装文案：

## 11. 原型时最容易漏的交互

1. 底栏字永远是「索引管理」。不要把状态写进按钮文字。
2. 角标是「几件事」，不是「几张失败照片」。悬停三句加起来可能小于角标，因为监视降级只在关注文件夹顶部说明。
3. 短任务不弹右下角浮层；失败或不可访问时浮层不自动走。
4. 两套暂停：任务行是 per task_id；索引进度底部是全局。`task_id == 0` 的行没有暂停/取消。
5. 三种「删索引」文案和范围都不同，确认按钮分别是「确认」「删除索引」「移除」。左栏「从图库移除」没有确认。
6. 离线、已关闭、索引已移除、正常，四套按钮不一样。不要给离线根画「全量重建」。
7. 「格式不支持」没有重试。忽略不是隐藏。
8. 没有 ETA。唯一带「约 N 秒」的框用户点不到。
9. 缩略图统计没回来时是「计算中…」，不是 0。
10. 关索引管理窗口、关右下角 ×，索引都继续。取消导入才回滚，文案强调现有索引未改动。
11. 「在 Finder 中显示」这七个字在非 macOS 也原样显示。
12. 帧时间直方图勾选框不要画成可用的诊断图。
