### 0.2 冲突待后续设计消解（本轮只记录，不改原型）

1. **危险动作拆分（必须记，不能用「永不写原图」愿望隐去实装）：** 产品有两套完全不同的删除。**FS-01「移到废纸篓？」会 `rename` 移动原文件**（Unix 启动盘 `~/.Trash`，外接卷 ` /Volumes/{卷}/.Trashes/{uid}`，跨卷失败，Windows 暂不支持且不会搬去假目录）。只删索引是另一套：单根彻底删除、索引进度里的全库删除（关注文件夹还在）、左栏「从图库移除」无确认且留下可恢复行（IDX-06）。v1.2 只有「从资料库移除」，正文承诺原文件留在原处，把两套合成了一个，且完全没有废纸篓。后续既要补 FS-01 的确认文案与范围，又不能在原型里真的移动文件；也不能删掉「只删索引」三条。
2. **缩略图尺寸控件：** A 要求顶栏 −/+（22–512，⌘−/⌘+/⌘0/⌘1/⌘2）；B 已确认底栏连续滑块（80–280）。两者并存还是合一，待设计，**不得先拆掉滑块**。
3. **查看器导航与缩放：** A 是左右点击区 + 连续缩放约 5%–800%，无胶片条、无适合/100%/200% 三按钮；B 已确认胶片条，原型另有三档缩放。三档与连续缩放如何并存待设计，**不得先拆胶片条**。
4. **索引入口壳层：** A 是底栏恒定「索引管理」+ IO pill + 延迟浮层 + 非模态五标签窗；B 已确认设置下级页和底栏可点入口。应将五标签与状态机装进已确认的新壳，而不是改回旧窗口当唯一入口。
5. **布局模式：** A 是方格 / 纵向瀑布流 / 横向瀑布流，**没有列表**；原型是方图 / 原比例 / 列表。列表属于 C（原型已加，不擅自删除，不能当实装）。两种瀑布流属于 A，目前缺失。
6. **「最近导入」：** 原型固定视图。实装是「最近更改」（SB-03）以及导入成功后的临时标题「本次导入 · N 张」（SF-15）。名称和查询都不同，待消解。
7. **整理入口位置：** 实装把收藏 / 说明 / 标签 / 托盘放在顶栏（无选中也显示，点了 toast「请先选择照片」）；原型放在选中后的底栏批量条。批量条本身不是实装控件。

### 1.2 侧栏与顶栏入口

- 侧栏分组（均不可折叠，宽度不可拖）：资料库（所有照片、最近导入、星标）→ 标签（＋、右键改名/删除）→ 相册（＋、右键打开/重命名/加入所选/删除；暗色为封面）→ 文件夹（无右键、无状态点）→ **图库来源**（产品无此组名，实装对应的是「导入的索引」且仅有导入来源时出现）→ **设置 / 索引管理**（B）。
- 底部照片托盘：展开/收起、清空（有确认）、点击缩略图打开查看器。无「右键移出该张」，无顶栏双态「移出照片托盘」。
- 顶栏图标：显隐侧栏、导入（进入演示向导）、**可播放幻灯片**、布局三连、搜索、排序、筛选、「…」。
- 「…」菜单：设置、索引管理、帮助、切换主题、恢复演示数据、**「导出索引包…」仅 toast**（文案写成「产品规划中的能力」——这与实装不符，索引包导出是已实现功能）。
- **没有**顶栏：收藏、说明、标签、托盘、−/+、编辑（产品编辑是可见未接通）。幻灯片在产品里也是未接通，原型做成了能播。

### 1.3 底栏、浮层、确认框

- 底栏左侧：连续缩略图滑块（B）。右侧：可点的索引进度，文案为「索引空闲 / 正在索引 / 已暂停 / 索引完成」+ `done / total` + 进行中百分比条。空闲时默认 `20 / 20`（用照片张数当总数）。**没有**恒定文案「索引管理」、没有失败角标、没有导入导出 pill。
- 选中后另有批量条：加星标、加入相册、标签、放入托盘、从相册移出（仅相册视图）、从资料库移除、取消选择。
- 模态确认（均与索引三套删除 / 废纸篓不同）：删除相册、删除标签、从资料库移除 N 张、清空托盘、恢复演示数据、从资料库移除来源。
- 输入框：新建/重命名相册或标签。
- 菜单：排序、筛选、更多、相册、标签、相册/标签右键。文件夹与照片**无**右键菜单（照片无右键与实装 GR-05 一致）。
- Toast、演示幻灯片覆盖层。
- **没有**库错误顶中红条、没有「正在建立缩略图索引」1.5s 浮层、没有「索引进度」详情窗、没有「移到废纸篓？」确认。

### 1.4 演示状态（设置 → 演示与数据）

资料库为空、目录失联、权限失败、加载中骨架、恢复演示数据。失联/权限是独立演示页，产品对应的是索引状态与 toast，不是独立路由（C）。

### 3.2 总览（五标签之上常驻）

图库根目录（空库警告句；否则每根一行 `{正常\|已关闭\|离线\|索引已移除} · {N} 张`，可加缩略图字节与失败数；离线警告色；字节 1024 进制） / 索引状态（● 最近 running 的七态文案，否则 ● 空闲） / 照片数量（只数未关闭根） / 最近更新（相对时间） / 仅 badge>0 时异常行（无「一切正常」）。相对时间粗粒度（刚刚 / n 分钟前 / … / 30 天前以上）。任务七态：`等待` `扫描中` `生成缩略图中` `已完成` `部分失败` `暂停` `不可访问`。任务类型：`首次索引` `刷新` `重建` `恢复` `回填尺寸` `校验`。

原型：无总览四字段，无七态/六类型。**全部 A 缺失。**

### 3.3 标签「任务」

- 失败分类五行固定顺序：无权限、文件损坏、目录失联、格式不支持、超时。count+ignored=0 不画；有则 `{count} 条`、`已忽略 {n}（仍可见）`；可重试且 count>0 才有「重试全部」；格式不支持改为灰字「不支持重试」；「忽略全部 / 取消忽略」。全空：「没有失败项」。本标签**不列出单张文件名**（单张在索引进度「查看失败项」）。
- 「清空任务历史…」：无已结束记录则禁用；需确认「确认清空任务历史」；只删已结束记录。
- 列表：进行中在前，历史最多 50，同一条不会两处都在。进行中：`已处理 {discovered} 张 · 已用 {mm:ss}`，**无百分比、无 ETA、无进度条**。终态：成功/部分失败/失败/已取消 + `完成 · 跳过 · 失败` + 可选取消原因。
- 按条暂停/继续/取消（`task_id==0` 不画）。系统暂停仅说明、**不能人为继续**。全局暂停在索引进度面板，不是任务页「暂停全部」。
- 启动续跑 toast。

原型：单任务 + 全局「暂停演示 / 继续索引 / 重建索引（演示）」+ 百分比条。**A 基本整页缺失**；全局三钮不能代替按条操作和按根重建。

### 3.4 标签「关注文件夹」

不是目录树。监视行、`为什么？` 五类说明、最近索引相对时间。状态字：离线优先于已关闭，为 `离线` / `索引已移除` / `已关闭` / `正常`。

- 索引已移除：正文强调标记还在、重新索引会挂回、原图未动；按钮只有 `重新索引（恢复）` · `在 Finder 中显示` · `删除索引`（「在 Finder 中显示」七个字在 Linux 也原样显示）。
- 离线：只有 `连接后刷新`、`删除索引`。不能画全量重建/关闭/重新打开/显示于 Finder。
- 在线：刷新、重新索引、强制重扫、全量重建（要确认）、关闭或重新打开、在 Finder 中显示、删除索引（要确认）。全量重建不先清空旧缩略图。
- 两套删除不是同一按钮：左栏「从图库移除」留下空壳；本页「删除索引」彻底删行。

原型来源三态完全对不上。**A 缺失。**

### 3.5 标签「排除项」

空：`没有已关闭的子目录`。有则「全部恢复」（无二次确认）、「清理失效项」（无失效则禁用；原型放一个能用按钮即可，不必复制源码里两个同名按钮的像素问题）、每行路径、`已失效`、`恢复`。

原型无。**A 缺失。**

### 3.6 标签「存储与诊断」

占用：索引库文件、WAL、缩略图（未算完必须「计算中…」，禁止显示 0）、照片张数。按根分布。操作：清理缩略图（确认）、VACUUM（无确认）、清空运行日志（确认，路径写死 `~/Library/Logs/app.openpicasa/openpicasa.log`）、导出诊断日志（系统选目录，成功文件名 `openpicasa-diag-{UTC}.json`，脱敏，界面不预览）。复选框「显示帧时间直方图」若保留须标明点了没有图（C 未接通）。页脚「不修改或移动原始照片」**只出现在导入/导出标签**，不要做成窗口常驻。

### 3.7 标签「导入 / 导出」（索引包，不是添加文件夹向导）

条件横幅：隐藏来源恢复、上次导出中断重来/忽略、上次导入提交前中断「知道了」、上次已提交摘要。导出：说明不含原片、勾选含缩略图、保存框默认名、最近成功备份（本地时间、SHA-256 前 12 位、路径、在 Finder 中显示）。导入：选择演示索引包（**严禁谎称生成真实 opicasaidx 格式**；可导出标清安全示例文件并标明非真实数据库）。校验中不确定条、取消校验、无 ETA。四步：① 校验与预览（无展开文件夹树、全包最多 12 张）② 策略与范围（合并默认 / 替换；都要勾「我已了解上述影响范围」，无另弹确认窗）③ 执行（已知总数可百分比且单调不回退；未知循环条不写百分比；取消导入回滚，强调现有索引未改动；无「暂停导入」）④ 结果与匹配（四计数、失败明细最多 50、浏览导入的照片、重新匹配根目录）。底部常驻六态操作状态。
