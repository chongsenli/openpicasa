## 已实现并在测试中覆盖、但未单独出 PNG 的项

- **权限失败**状态：设置「演示：权限失败」，自动化测试已断言「没有访问权限」。版式接近空状态，未再出一张专用图。
- **创建 / 重命名相册或标签**的输入对话框：测试已走通「新建相册 → 命名为 原型相册」。
- **主题切换并跨页保持**：测试覆盖设置页切换后，在帮助页与图库页仍为同一主题。
- **方图 / 原比例 / 列表**切换：工具栏可点，原比例会做简易两端对齐布局。本包未逐一截三种布局。
- **筛选菜单、排序菜单、评分保持、导入四步、查看器往返**：见 `TEST-RESULTS.md`。
