# OpenPicasa 交互原型 v1.4

这是一份可供评审和交接的**离线桌面照片管理交互原型**，不是已发布的 OpenPicasa 产品，也不是生产代码。视觉沿用已确认的融合版：亮色为方案 A 清场 + HeroUI Pro，暗色为方案 B 暗房 + beUI Pro。查看器为展厅结构（主图 + 说明 + 胶片条 + 可开关的右侧「照片信息」栏）。

功能覆盖与模拟边界以 `docs/FEATURE-MAP-v1.4.md` 为准（v1.3 映射仍保留作对照）。事实基线是源码审计，本包**没有**附带 Rust 仓库，也不声称运行过真实桌面应用。

**v1.4 按用户最新明确改动，覆盖此前已确认、但与本轮冲突的入口布局。** 只收拢入口，不删除设置页或索引管理页的已实现能力。

## 如何打开

1. 解压后进入本文件夹，**双击 `index.html`**，用 Chrome、Edge 或 Safari 打开即可。
2. 也可以把该文件拖进浏览器，或使用 `file://` 路径打开。不需要本地服务器，不依赖 CDN，不会去拉取本地 JSON。
3. 设计视口约为 1280×820。窗口更大时原型会居中显示；更小时会铺满当前窗口。

首次打开即是演示资料库。整理关系（收藏、说明、标签、相册、主题、缩略图边长、侧栏宽度等）写入浏览器 `localStorage`，键名 `openpicasa.prototype.v1`。若存储不可用，会退回到本次会话的内存状态。

## 主要流程

- **浏览**：侧栏分组顺序为 **图库 → 标签 → 相册 → 文件夹 → 导入的索引**（有导入来源时出现，紧挨文件夹之后）→ 底部照片托盘。图库仍靠上。文件夹子树、右键与折叠仍可用。侧栏已去掉整个「设置」组及其「索引管理」子项。
- **选择与整理**：单击、⌘/Ctrl 单击、Shift 范围、从空白拖矩形框选（占位格不计入）。顶栏可收藏、写说明、打标签、放入或移出托盘。批量栏主危险按钮是「移到废纸篓…」。
- **添加文件夹（演示）**：只用**顶栏导入按钮**打开演示目录选择器（设置页「图库来源」里的同一入口也保留）。更多菜单已去掉「添加文件夹…」。按产品规则反馈（已在库中、包住已有根、落在范围内、无权限、目录不存在）。不会打开系统文件选择器，不会读取你磁盘上的真实照片。空库提示改为「点顶栏的导入按钮」，不再指向已删除的「… → 添加文件夹…」。
- **展厅查看器**：双击进入。左右或 J/K 切换，胶片条，连续缩放 5%–800%（适合 / 100%、滚轮与键盘，查看器工具条上的 −/+ **本轮保留**），C 并排比较，空格切换背景，I 开关「照片信息」。进入时有「正在载入原图… / 正在解码…」，鼠标静止会隐藏 chrome。底栏有文件名、宽高、第 i/n 与缩放。「显示位置」和 ⌘Enter 只演示，不打开访达。无 EXIF 的条目显示「无拍摄信息」；有字段的均标为示例元数据。Delete 走废纸篓确认。
- **缩略图尺寸**：底栏最右侧是「缩略图」滑块 + 像素值，连续 22–512 px（线性 step=1），实时更新并跨页持久化。顶栏已去掉缩略图 −/+；⌘− / ⌘+ / ⌘0 / ⌘1 / ⌘2 仍与滑块共用同一状态。
- **设置与索引管理（入口已收拢）**：更多菜单保留「设置…」（⌘,）。打开设置页后，用「打开索引管理」进入 `#/settings/index`。更多菜单仍保留已有的「索引管理…」作为直达项，但侧栏与底栏不再放置该入口，也没有在顶栏加齿轮。底栏已完全去掉「索引管理」按钮、红角标和整区可点入口。索引任务运行中，必要的「已处理 N 张 · 已用 mm:ss」以及 IO 进度显示在底栏**左侧**（纯状态，不可点），或沿用原来的 1.5 秒浮层；不会挤到滑块右侧。
- **索引管理页**：含总览与五个标签：任务、关注文件夹、排除项、存储与诊断、导入 / 导出。未知总数只显示已处理张数和耗时，没有假百分比或 ETA。切页不会中断正在运行的演示任务。
- **帮助**：快捷键与覆盖说明已按 v1.4 入口更新，并单独标明演示扩展。

## 相对 v1.3 的入口改动（覆盖旧确认）

以下以本轮用户要求为准，不再沿用 v1.3 README / 映射里相冲突的旧确认：

- 侧栏顺序改为标签、相册在文件夹之前；去掉侧栏设置组。不是删除设置/索引页面。
- 底栏去掉「索引管理」常驻按钮与角标；缩略图滑块（含像素值）改到最右侧。
- 顶栏只去掉缩略图 −/+ 及其占位；布局切换等其它顶栏功能保留。查看器缩放 −/+ 未要求去掉，仍然保留。
- 更多菜单去掉「添加文件夹…」；空库提示改指顶栏导入。

仍请勿沿用更早版本的文案：缩略图不是 80–280 或三档；空闲底栏不会出现「20 / 20」或百分比；三种实装布局是方格与两种瀑布流；主危险操作是「移到废纸篓」（产品会移动原文件；本原型只模拟）；索引导出是演示 JSON；查看器缩放是连续范围。

## 演示限制（请勿当作已实现的产品能力）

- 应用**不会**向原照片文件夹写入、移动或删除任何真实文件。收藏、说明、标签、相册只模拟独立资料库。
- 「移到废纸篓」在真实产品中会 `rename` 原文件到系统废纸篓。本原型只从演示库移除条目，并在确认框写明这一差别。
- 导入、重定位、选索引包全部使用内置演示项，不打开系统文件选择器，不扫描真实磁盘。
- 导出的 `photo-index-demo.json` / `openpicasa-diag-demo.json` 带警告句，不能被正式应用导入。
- 拍摄信息除本地演示 JPEG 的宽高与体积外，均为**界面示例**，不是真实 EXIF。直方图是示意图。
- 标有「演示扩展」的能力（可播幻灯片、1–5 评分、列表布局、从相册移出、最近导入、恢复演示数据）可以点，但**不是产品已实现**。
- 「编辑」等未接通入口只提示下一版开放。
- 未承诺百万张虚拟滚动或真实磁盘监视。监视降级、离线根目录等均是演示状态。

## 审核演示场景

打开 **更多菜单 → 设置… → 演示与数据**（不要从侧栏或底栏找这些按钮）：

索引进行中、系统暂停、系统恢复、失败分类、离线根目录、监视降级、导入中断回滚、导出中断、启动校验；以及资料库为空、目录失联、权限失败、加载中。用「退出演示状态」或「恢复演示数据」回到默认库。失败分类会在图库注入异常格；失败计数在设置 → 索引管理中查看，底栏不再使用失败角标按钮。
