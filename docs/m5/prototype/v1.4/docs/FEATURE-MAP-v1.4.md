## 0. v1.4 覆盖此前已确认的入口布局

用户最新明确改动（授权 round 覆盖与之冲突的旧要求）：左侧 sidebar 将文件夹放到标签、相册之下，去掉设置；bottombar 去掉索引管理，把缩略图滑杆放到最右侧；topbar 去掉加减符号；更多弹出框去掉添加文件夹。

这是 **B 壳入口重组**，不是删除 A 能力：

| 项目 | v1.3 及更早曾确认、本轮覆盖 | v1.4 实际入口 |
| --- | --- | --- |
| 侧栏分组顺序 | 图库 → 文件夹 → 导入的索引 → 标签 → 相册 → 设置 | **图库 → 标签 → 相册 → 文件夹 → 导入的索引**（有来源时紧挨文件夹之后）→ 托盘。文件夹子树 / 右键 / 折叠仍工作。 |
| 侧栏设置组 | 设置 + 缩进「索引管理」 | **整组删除**，不留空标题或孤立子项。设置页与索引页本身保留。 |
| 底栏索引管理 | 右下角常驻「索引管理」按钮 + 红角标，整区可点进入 `#/settings/index` | **完全去掉按钮、角标、可点入口**（不换名保留）。运行中「已处理 N 张 · 已用 mm:ss」与 IO pill 作为**不可点状态**放在底栏左侧，或走原 1.5 秒浮层；不得出现在滑块右侧。 |
| 缩略图滑块 | 底栏左侧滑块，右侧是索引入口 | **滑块 + 像素值作为一组贴最右**。范围 22–512、线性 step=1、实时连续、跨页持久化不变。 |
| 顶栏 −/+ | 布局切换旁的缩略图缩小/放大 | **去掉缩略图 −/+ 及其占位**。布局切换等其它顶栏功能保留。查看器缩放 −/+ **未要求去掉，仍保留**。⌘−/+/0/1/2 仍可用。 |
| 更多菜单添加文件夹 | 第一项「添加文件夹…」 | **去掉**。添加文件夹改走仍存在的**顶栏导入**（设置页来源按钮也保留）。 |
| 空库提示 | 「点顶栏「…」→「添加文件夹…」」 | **改指顶栏导入按钮**，避免死指引。 |
| 设置 / 索引可达 | 侧栏 + 底栏 + 设置页 + 更多 | **更多菜单「设置…」（优先保留已有项）→ 设置页「打开索引管理」**。更多菜单仍保留已有「索引管理…」直达。不在顶栏新增齿轮，不重建侧栏设置组。 |

## 1. 模拟总边界（对所有行有效）

- 本原型是离线 `file://` HTML，**绝不读写、移动、删除或扫描用户真实照片**。
- 「移到废纸篓」只从演示资料库移除条目并弹出准确产品说明；不会操作 `~/.Trash` 或任何磁盘路径。
- 添加文件夹 / 重定位 / 选索引包都走**演示选择器**，不打开系统文件对话框。选择器标题为「选择照片文件夹（只读，不会修改你的文件）」。
- 索引导出、诊断导出是**标清演示 JSON / TXT**，文件内有警告句，不能被正式应用当 `.opicasaidx` 导入。
- 拍摄信息除本地演示 JPEG 的宽高与体积外，均为界面示例。筛选里的 PNG/GIF/WebP/TIFF/SVG/HEIC/AVIF/RAW 是**演示格式标签**，对应条目仍使用包内 JPEG 资源，不会解码真实这类文件。
- 演示场景入口只在设置页「演示与数据」，不占用主界面结构。含「演示：库错误红条」「演示：未完成任务（刷新后续跑）」。
- OS 集成（访达、系统文件对话框、真实废纸篓、磁盘监视、真实 EXIF 读取、真实索引库文件）只模拟，这是合理边界，不要求本原型做真实文件操作。

## 5. 旧测试语义，不可再称「全通过」

v1.0 / v1.1 / v1.2 自动化里下列断言**已被产品正确语义修正**，即使旧脚本变红，也不能再宣传 39+28+21「全部通过」：

- 底栏或索引页出现 **`20 / 20`、百分比、`data-pct`、ETA、空闲仍显示总数** —— v1.4 在未知总数时只显示已处理张数与耗时（底栏左侧只读）；空闲底栏不再出现「索引管理」按钮。
- 缩略图范围 **80–280** 或三档尺寸 —— 现为 22–512 连续滑块。
- 布局名称「方图 / 原比例 / 列表」作为唯一布局 —— 现为方格 / 纵向瀑布 / 横向瀑布；列表只是扩展。
- 危险操作文案「从资料库移除」当作删除照片的主路径 —— 主危险路径改为「移到废纸篓」（模拟）。
- 查看器三档缩放（适合/100%/200%）作为唯一缩放 —— 现为连续缩放 + 适合/100%。
- 帮助文案把索引导出包写成「未规划能力」—— 现为可演示的导入/导出，且标明演示格式。
- 排序文案「尚无缩略图的排在前面」—— 正确语义是「有缩略图的排在前面」。
