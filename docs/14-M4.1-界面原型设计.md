### 0.0 工具栏图标形状对照（M4.1 增量）

继承 `12` §0.0 的 13 枚 SVG 对照，本节只列 **M4.1 新增/复用的 4 枚**。**图标全部为 `icons.rs` 矢量自绘**（不引外部资源、不引 SVG 光栅化依赖，`icons.rs:1-12`）；HTML 原型把它转成内联 SVG（`stroke=currentColor`）。

### 6.3 egui 落地路径（实现红线）

egui/epaint **没有** `backdrop-filter`，不能对已绘制背景实时模糊。因此：

1. `topbar.rs::show` 开头调 `glass::GlassUnderlay::get(ctx, GlassKey{width,height,dark})`：
   CPU 端生成 1/4 分辨率的**中性灰白** `ColorImage`（无彩色背景，v1.4 用户要求），
   做 **3 次可分离 box blur（≈高斯）**，`ctx.load_texture` 缓存为 `TextureHandle`；
2. 每个按钮把这张纹理的**对应子矩形**贴进自己的 rect（`RectShape::with_texture`），再叠 ②～⑥；
3. 缓存只在「顶栏宽 / 侧栏宽 / 主题 / DPI」变化时失效重算，**其余帧零重算**；折射用「子矩形 UV 轻微偏移」近似（默认不做逐像素折射）；
4. 水波纹只在波纹存活期用 `request_repaint_after` 驱动，结束即停，不常驻重绘（R-M41-1）。

- **不启用系统 vibrancy** / `NSVisualEffectView`，不引 `objc2` / `cocoa`（P-M41-07 v1.1）。
- 对比度 ≥ 4.5:1（`10` M32-UI-13）；`filter_active` 蓝圆描边、`−/+` 端点置灰、tooltip **一律保留**。
- 模糊底图每帧生成 0 或 1 次、不新增缩略图纹理上传，滚动 p99 ≤ 25 ms 不回退（R-M41-2）。
- **反证验收**：临时关掉顶栏底图，玻璃感应明显消失 —— 证明「可透内容」真的接上了，而不是又一层半透明白。

> 参考（外部资料，仅作视觉参照）：[Tessera UI](https://tessera-ui.github.io/)、[Fluid Glass](https://tessera-ui.github.io/zhHans/components/fluid_glass.html)、[Glass Button](https://tessera-ui.github.io/zhHans/components/glass_button.html)、[用户最初给的 Slider 页](https://tessera-ui.github.io/zhHans/components/slider.html)；动图 [`glass_button_example.gif`](https://tessera-ui.github.io/glass_button_example.gif) 取样：红底 `(195,6,36)` 透过玻璃变浅粉 `(244,177,179)`。

## 10. 设计红线与非目标

| 红线 | 原型如何守 |
| --- | --- |
| 不改三行骨架 | 顶栏 / 标题 / 状态栏高度一律不动；新内容只落工具栏左段、网格绘制层、既有弹层 |
| 不改三段语义 | 四新钮属「对象操作」落左段；中段仍是浏览设置；右段仍是查找与更多 |
| 单一真相源 | 四按钮 / 浮层 / 底栏 / 角标共读 `lib.selection` |
| 不放假入口 | 无选中时 toast 提示而非灰按钮；「编辑/幻灯片」占位维持 M4 现状，本版不伪装成可用 |
| 零写入 | 四按钮只写自有 DB / Preferences；界面无「写回原图」「包含原图」等选项 |
| 不回退性能 | 不新增纹理上传、不每帧 `request_repaint()`、不改 `m4_exif` / 左栏缓存路径 |
| 失败不静默 | 批量失败走 toast；筛选「全部」不等于「清除全部筛选」，职责分明 |
| 不显示 ETA | 框选 / 批量操作无进度条、无百分比 |
| 版权红线 | 4 枚图标全部 `icons.rs` 矢量自绘（2 枚新增 2 枚复用），不提取原版资源、不引 SVG 光栅化依赖 |

**非目标**（不在本原型）：模态对话框、系统 `NSVisualEffectView` vibrancy、框选边缘自动滚动 / 跨页框选、微缩图集圆角、上下文操作栏（选中浮出的第二批按钮）、照片编辑与幻灯片真实功能、列表视图、深色主题、像素级视觉定稿（归 `docs/ui-baseline`）。
