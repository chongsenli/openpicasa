# 09-M3.1 实现功能清单

> **文档定位**：接 `docs/08`（M3 版本说明）。M3.1 是一次**界面重构里程碑**，
> 不新增任何数据层/引擎层能力，`cargo test --workspace` 全绿、clippy 零告警。
>
> **需求来源**：用户 2026-11-03 指令——「整体布局除预览图片区域外像素级模仿
> 参考截图（macOS『照片』app 风格）；视图三个子菜单模仿截图的『年 / 月 / 所有照片』
> 按钮；去掉『缩略图』按钮；状态栏缩放滑块改成截图里的加号和减号按钮、放进顶栏；
> 风格像素级模仿截图」。
>
> **用户拍板的两个取舍**（2026-11-03 问询确认）：
> 1. 分段控件的三个选项 = 原「视图」菜单的三项（方格 / 纵向瀑布流 / 横向瀑布流），
>    而不是截图字面的「年 / 月 / 所有照片」——模仿的是**版式**，不是照搬功能；
> 2. 左栏**保留现有功能条目**、按截图风格重绘，不放假条目
>    （截图里的「精选集 / 固定 / 相簿列表」在本应用没有对应功能）。

### 1.2 弹层观感（macOS 化）

排序菜单、筛选面板、「…」菜单统一改为**白卡 + 圆角 8px + 柔影**（原 XP 直角灰边）；
菜单项整行可点、选中项带 ✓；交互逻辑（打开帧豁免、点空白关闭）不变。

### 1.3 新图标（13 枚，`icons.rs` 矢量绘制）

`Plus` / `Minus` / `SidebarToggle` / `SortArrows` / `ListLines` / `Ellipsis` /
`Share` / `Heart` / `Album` / `PhotoStack` / `Map` / `Video` / `Person`。

沿用既有结论：**不提取原版资源、不引 SVG 光栅化依赖**，视觉重量对齐截图、
笔触不逐像素复刻（版权与依赖树的同一套红线）。

### 1.4 快捷键

| 键 | 行为 | 变化 |
| --- | --- | --- |
| `⌘+` / `⌘−` | 缩略图放大/缩小一格（对数档） | **新增**（原查看器内才有 +/-） |
| `⌘1` / `⌘2` | 缩小一格 / 放大一格 | 语义从「跳到刻度点」改为「对数档步进」，与顶栏按钮同路径 |
| `⌘0` | 回默认刻度（128px） | 不变 |
| `⌘⇧R` | 含子文件夹 | 不变（入口改到「…」菜单） |
| `⌘F` | 聚焦顶栏搜索框 | **新增** |

## 2. 修改 / 移除

| # | 变更 | 理由 |
| --- | --- | --- |
| 1 | **「缩略图」循环三刻度按钮移除** | 用户指令「去掉缩略图的按钮」。缩放能力由顶栏 −/+ 完整承接（12 对数档 ⊇ 原 3 刻度点） |
| 2 | **状态栏缩放滑块移除**（`statusbar.rs`） | 用户指令「缩放滑动条变成图片里面的加号和减号按钮，放到顶栏中」。状态栏保留：视图名·计数、已选数、诊断入口、索引入口（唯一入口原则不变） |
| 3 | **XP 菜单栏（档案/视图/说明）移除** | 截图无菜单栏。功能全部迁走：添加文件夹→「…」、排序→顶栏图标、全屏→「…」、关于→「…」。**零功能丢失**（`07` R-M22-5 的同款检查在此重做了一遍） |
| 4 | **XP 工具行（添加文件夹/显示位置/排序/缩略图/视图/筛选/搜索范围/含子文件夹/全屏/返回）退役** | 同上。「显示位置」保留在照片右键与 `⌘↩`；「返回」按钮无真实功能（M1 起恒禁用）顺势退役 |
| 5 | **「视图」弹出菜单移除** | 三项搬进顶栏分段控件（用户拍板） |
| 6 | **左栏重绘（照片风格）**：行高 22→36px；拟物文件夹图标→线性描边图标；组头渐变白盒+绿色折叠钮→灰色小字分组标题（"图库"/"文件夹"，右端折叠箭头）；选中行钢青蓝白字→浅灰胶囊+深字；左栏底 #F3F3F3→#F5F4F2 | 用户指令「风格像素级模仿截图」 |
| 7 | **左栏条目集合不变** | 用户拍板：保留现有功能，不放假条目 |
| 8 | **栅格背景 #F2F2F2→白色；日期分组头、单元格描边等沿用** | 截图内容区为白底 |
| 9 | **筛选面板动作解耦**：从 `ToolbarAction` 拆出 `FilterPanelAction` | 枚举不再互相嵌套；筛选功能本身不变 |

## 3. 与参考截图的已知偏差（登记）

| 偏差 | 理由 |
| --- | --- |
| 分段控件文案是「方格/纵向/横向」而非「年/月/所有照片」 | 用户拍板：三个选项 = 现有视图模式，模仿版式不照搬功能 |
| 左栏条目是「图库/文件夹」而非「图库/精选集/固定/相簿」 | 用户拍板：不放假条目 |
| 顶栏图标组的 ⓘ/分享/收藏是占位（toast 说明） | 本应用尚无这些功能；宁可是**显式的占位**也不做假交互 |
| 「最近删除」无入口 | 本应用删除走系统废纸篓，无应用内回收站 |
| 红绿灯位置依赖 eframe 每帧回调 | AppKit 会在窗口布局时重置按钮位置，`set_traffic_lights_position` 必须每帧调（eframe 文档明示） |
| 非 macOS 平台 | 红绿灯占位宽度退化为 8px，顶栏其余布局一致；`fullsize_content_view` 仅 macOS 启用 |

## 6. 给下一个人的三条提醒

1. **`zoom` 的「拖动中不换纹理」机制没有删**：顶栏 −/+ 是离散动作，走
   `drag_to + end_drag`（立即结算）；`ZoomState` 的连续拖动、锚点、回滞逻辑
   原样保留——将来如果加「捏合缩放」或恢复滑块，直接复用，别重写。
2. **红绿灯占位宽度 `traffic_w = 78` 是 macOS 专用值**：它补偿的是系统三枚按钮
   的横向空间。改顶栏左侧布局时先在非 macOS 上确认没有被多让出 70px。
3. **分段控件与「视图」菜单是替代关系**：如果将来加第四种布局（比如「年/月」
   分组浏览），应**扩分段控件的片数**而不是恢复弹出菜单——用户 M3.1 的拍板
   就是「子菜单收进顶栏」。
