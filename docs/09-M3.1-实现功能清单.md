## 3. 与参考截图的已知偏差（登记）

| 偏差 | 理由 |
| --- | --- |
| 分段控件文案是「方格/纵向/横向」而非「年/月/所有照片」 | 用户拍板：三个选项 = 现有视图模式，模仿版式不照搬功能 |
| 左栏条目是「图库/文件夹」而非「图库/精选集/固定/相簿」 | 用户拍板：不放假条目 |
| 顶栏图标组的 ⓘ/分享/收藏是占位（toast 说明） | 本应用尚无这些功能；宁可是**显式的占位**也不做假交互 |
| 「最近删除」无入口 | 本应用删除走系统废纸篓，无应用内回收站 |
| 红绿灯位置依赖 eframe 每帧回调 | AppKit 会在窗口布局时重置按钮位置，`set_traffic_lights_position` 必须每帧调（eframe 文档明示） |
| 非 macOS 平台 | 红绿灯占位宽度退化为 8px，顶栏其余布局一致；`fullsize_content_view` 仅 macOS 启用 |

## 6. 给下一个人的三条提醒

1. **`zoom` 的「拖动中不换纹理」机制没有删**：顶栏 −/+ 是离散动作，走
   `drag_to + end_drag`（立即结算）；`ZoomState` 的连续拖动、锚点、回滞逻辑
   原样保留——将来如果加「捏合缩放」或恢复滑块，直接复用，别重写。
2. **红绿灯占位宽度 `traffic_w = 78` 是 macOS 专用值**：它补偿的是系统三枚按钮
   的横向空间。改顶栏左侧布局时先在非 macOS 上确认没有被多让出 70px。
3. **排布控件与「视图」菜单是替代关系**：定稿为**无文字三图标连体胶囊**（方格/
   纵向瀑布/横向瀑布），不是年/月/所有照片。若将来加第四种布局，应**扩该连体
   片数**而不是恢复弹出菜单；完整中文名仅用于 tooltip。详见 §7。

## 7. 首页布局定稿（2026-11-03，接竞品调研后改版）

> **状态**：产品已定稿，**代码已按本节重排（2026-11-03）**。实现以本节为准，
> 覆盖 §1.1 顶栏/§2 左栏中与本节冲突的版式描述；数据层仍零新增。
>
> **依据**：Kevin 竞品调研 + 三版方案选型；Eason 定稿 **B 双语境为主**，吸收 A 的方格文件名可选项与 C 的本地信任提示，并确认三行布局与底栏「索引管理」。

### 7.1 整体骨架（三行一列）

| 行 | 区域 | 内容 |
| --- | --- | --- |
| 1 | **工具栏**（通栏） | 红绿灯 + 操作/排布/缩放/搜索等控件；**不含**大号文件夹标题、不含文件树 |
| 2 | **中区**（左右分栏） | **左**：当前文件夹标题「京都」类小字标题 + 张数·日期跨度副标题，**其下**为文件夹树；**右**：照片预览（方格 / 纵向瀑布 / 横向瀑布） |
| 3 | **状态栏**（通栏） | 左侧信任文案等；**最右侧**为「索引管理」入口 |

文件树**不得**做成通栏通高侧栏压住整窗；树挂在中区左侧、标题之下。

### 7.2 工具栏控件（第一行）

从左到右约定（图标优先、中文可作 tooltip）：

1. **导入 / 幻灯片 / 编辑**：三枚**原型圆形图标按钮**，**无文字**（功能来自方案 A 工具台）。
2. **排布**：三枚图标**连体胶囊**（造型对齐 −|+），**无文字**；语义依次为「方格」「纵向瀑布」「横向瀑布」（完整文案仅用于 tooltip / 无障碍名）。选中片高亮。**禁止**做成 Apple「年|月|所有照片」式中央时间胶囊。
3. **− / +**：对数档缩放，连体胶囊（既有行为保留）。
4. **搜索**：图标按钮，紧接在 **+** 之后。

> **实现补充**：搜索默认只画放大镜图标；点击（或 `⌘F`）后原地展开输入框，
> 左端保留「文/全」搜索范围切换，右端是收起按钮。排序 / 筛选 / 「…」保留为
> 最右侧图标组（既有功能不丢）；「…」菜单内新增「方格显示文件名」开关。

### 7.3 中区左侧（标题 + 文件树）

- 标题：当前文件夹名，字号**小于**早期效果图中的展示级大标题（约正文偏大一档即可）。
- 副标题：`N 张 · 拍摄日期跨度`（双语境；根目录/「全部照片」时弱化面包屑、副标题改总量与日期跨度）。
- 文件树：**条目集合仍按现有图库/文件夹功能，不放假条目**；**视觉样式仿方案 A**（文件夹图标、树线、更密行高），不是 Photos 大行高列表。

### 7.4 中区右侧（预览）

- 三种排布：方格 / 纵向瀑布 / 横向瀑布（既有视图模式）。
- **方格文件名**：方格模式下提供「显示文件名」**可选项**（吸收 A；迁移用户建议默认开，最终默认值实现时可再确认）。
- 纵向/横向瀑布：文件名默认弱化或不显示（悬停或关）。

### 7.5 状态栏（第三行）

| 位置 | 内容 |
| --- | --- |
| 左 | 轻量信任提示：「**本地 · 不改原文件**」（吸收 C） |
| 中 | 既有：视图语境计数、已选数等（可精简，避免与标题副标题重复堆砌） |
| **最右** | **「索引管理」**：打开既有索引管理流程的**唯一显式按钮入口**（与「索引入口唯一」原则一致；从原状态栏/其它入口收敛到此位） |

说明：索引管理**不进**第一行工具栏；固定在底栏最右侧。

### 7.6 落地优先级（实现顺序建议）

1. 三行骨架 + 工具栏图标化排布/操作/缩放/搜索
2. 中区：小标题 + A 样式文件树 | 预览
3. 状态栏：信任文案 + **最右「索引管理」**
4. 方格「显示文件名」开关

### 7.7 验收要点

- [x] 窗口为三行结构；文件树在标题下、中区左侧，非通高侧栏
- [x] 导入/幻灯片/编辑为无文字原型图标；排布为无文字连体三图标；搜索在 + 后
- [x] 排布语义为方格/纵向瀑布/横向瀑布，非年/月/所有照片
- [x] 方格可选显示文件名
- [x] 状态栏左侧可见「本地 · 不改原文件」；**最右侧**为「索引管理」且可打开既有索引 UI
- [x] 不新增数据层能力；`cargo test --workspace` / clippy 门禁不回退
