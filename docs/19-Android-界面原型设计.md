## 0. 为什么是「翻译」而不是「照搬」

桌面端是**鼠标 + 大窗口 + 三行骨架（顶栏 / 左栏 + 主区 / 状态栏）**：`docs/11` §2.1 把它锁成「三行骨架」，
左栏常驻文件夹树 + 收藏 + 托盘，顶栏三段按钮，状态栏显示选择数/总数/磁盘空间。手机上**没有常驻左栏、没有三行、没有鼠标框选**，
所以不能直接缩桌面窗口。本原型把同一套信息架构重新落到手机形态：

| 桌面概念（来源） | Android 落点 | 为什么 |
| --- | --- | --- |
| 三行骨架（`11` §2.1） | **单行 TopAppBar + 底部导航 3 Tab + 手势条** | 手机纵向空间宝贵，常驻侧栏不可用 |
| 左栏文件夹树 / 收藏（`12` S0） | **「文件夹」Tab 的全屏列表 + 导航抽屉（Navigation Drawer）** | 树变成可返回的一级列表，点进去看该文件夹栅格 |
| 照片托盘（`F1-19`） | **多选模式的「已选 N」底栏 + 「加入托盘」动作** | 托盘是跨文件夹累积的临时集合，手机上用多选底栏承载 |
| 框选多选（`14` §4） | **长按进入多选 + 点选连选**，无橡皮筋框选 | 触摸没有 hover/拖拽框选的精确性 |
| 顶栏三段按钮（`10` M32-UI-02） | **TopAppBar 溢出菜单 + FAB + 上下文操作栏（CAB）** | 高频动作收敛到 1 枚 FAB，低频进菜单 |
| 状态栏数字（`F1-20`） | **栅格分组头 + 多选底栏计数 + 索引页单一快照** | 与 `11` §2.1.2「五处读同一份快照」同源 |
| 全屏查看器（`F2`） | **沉浸式全屏 + 双击缩放 + 双指捏合 + 左右滑翻页 + 上滑出信息面板** | 手势替代键盘/滚轮 |
| 索引管理窗口（`12` S1） | **「索引」Tab 全屏页 + 非模态小窗/通知** | 关闭 ≠ 取消任务，后台继续跑（`12` §0.2） |

**保留不变的产品内核**（来自 `README.md` 与 `01`）：
- **照片目录零写入（R-1）**：Android 上等价于「通过 MediaStore / SAF 只读访问，不写 `.picasa.ini`、不改原图 mtime」；数据只落自家 App 私有目录。
- **编辑室入口不存在（R-2）**：Android 原型**没有**任何「编辑/滤镜/旋转写回」入口，旋转只按 EXIF Orientation 显示。
- **单一真相源**：索引数字来自同一份快照，不出现「四个地方四个数字」。
- **失败不静默 / 不显示 ETA**：进度只给「已处理 N / M」或「已处理 N 项」。

## 1. 平台假设与设计基线（探讨口径）

> 这些是**设计假设**，不是已裁决的需求；若立项，需按 `15`/`16` 的 P 项流程逐条裁决。

| 项 | 假设值 | 依据 / 影响 |
| --- | --- | --- |
| 形态 | 手机竖屏为主，兼容折叠屏展开 / 平板 | 平板可回到「侧栏 + 栅格」双栏（见 §10 非目标里的「不做平板专属布局」） |
| 设计语言 | **Material 3 (Material You)**，动态取色默认关（沿用项目单色主题，见 `12` §11 非目标「深色主题」历史） | 不照搬桌面白圆底按钮，改用 M3 的 Filled / Tonal / Outlined 三级按钮，对应 `10` M32-UI-12 三级按钮语义 |
| 参考画布 | **360 × 780 dp**（≈ 1080 × 2340 px @3x），状态栏 24dp、手势条 16dp | HTML 原型按此画手机外框 |
| 导航 | 底部 **3 Tab：照片 / 文件夹 / 索引**（相册/标签并入「照片」Tab 的顶部分段或抽屉） | 避免 4+ Tab 挤压；与桌面左栏分组语义对应 |
| 图片来源 | **MediaStore + SAF**：只读系统图库与用户授权的目录 | 与 R-1 一致；Android 10+ 分区存储下不能乱写共享目录 |
| 索引 | 复用「后台扫描 / 缩略图 / 进度六态 / 离线失联」语义（`11` §2.1.2、`18`） | 不承诺复用桌面 Rust 引擎（见 §10 非目标） |
| 深色主题 | **跟随系统**（M3 默认），但本原型只画浅色一版 | `12` §11 曾把深色主题列为非目标；Android 平台惯例是跟随系统，这里标为「待裁决 P 项」 |

### 1.1 与桌面端样式基线的关系

桌面 M4.1 v1.8 定稿是「白圆底 + 加深阴影 + 发丝边」（`docs/ui-baseline/README.md` §「M4.2 基线说明」），
且 v1.7 已**整体删除玻璃态**（9 个玻璃 token 全作废，R-M42-3）。Android 原型：
- **不**恢复玻璃态、不引入彩色顶栏底图；
- 把「白圆底按钮」的**语义层级**（主要/常规/当前态）映射到 M3 的 Filled / Tonal / Outlined，而不是照抄像素；
- 星标角标（M42-UI-01）、查看器标签 chips、≤48px 档 8px 圆角（M42-UI-02）等增量视觉**保留语义**、在手机上重画。

## 3. 屏幕线框

> 线框为等宽示意；`[ ]` 控件、`●` 角标、`░` 缩略图占位、`★` 星标、`≡` 菜单、`＋` FAB、`▁` 手势条。
> 手机外框固定 360dp 宽；HTML 原型用 CSS 还原同样信息层级，不追求 1:1 像素。

### S1 · 空库首屏 / 首次引导

```
┌──────────────────────────────┐  ← 状态栏 9:41 ▮▮▮
│  OpenPicasa            [≡]    │  ← TopAppBar
├──────────────────────────────┤
│                              │
│          ( 空态插画 )         │
│       「还没有照片」           │
│   添加文件夹即可开始浏览       │
│   我们只读，不改你的照片        │  ← R-1 文案前置
│                              │
│  [ 添加文件夹 ]  ← Filled 主按钮│
│  [ 从系统图库导入 ]            │  ← Outlined
│                              │
│  ── 或选择扫描方式 ──         │
│  ○ 典型位置（相机/下载/图片）  │
│  ○ 整个设备                   │
│  ○ 暂不扫描（跳过）            │
│                              │
├──────────────────────────────┤
│ [照片]  [文件夹]  [索引]      │  ← 底部 3 Tab
│            ▁▁▁▁              │  ← 手势条
└──────────────────────────────┘
```

设计要点：空态三选一与 `F1-01` 一致；「我们只读，不改你的照片」把红线 R-1 变成首屏承诺，不等用户撞墙。
「暂不扫描」跳过后，主界面给「添加文件夹」空态引导（原型 S3 的空态分支）。

| 状态 | 触发 | 界面反馈 | 来源 |

## 8. 与桌面端的差异登记（有意偏离）

| # | 桌面口径 | Android 口径 | 理由 |
| --- | --- | --- | --- |
| D-01 | 三行骨架 + 常驻左栏（`11` §2.1） | TopAppBar + 3 Tab + Drawer | 手机无常驻侧栏空间 |
| D-02 | 鼠标框选（`14` §4） | 长按多选 + CAB | 触摸无精确框选 |
| D-03 | 白圆底按钮 + 加深阴影（M4.1 v1.8） | M3 Filled/Tonal/Outlined | 平台设计语言不同，仅保留「三级」语义 |
| D-04 | 相册写 `.picasa.ini`（`F5-05`，**这是原版口径，本项目 v3.0 已作废**） | 相册落自家 App 数据库 | R-1 数据自立；本列按项目 v3.0「数据自立」修正，桌面实装也未写 ini |
| D-05 | 深色主题为非目标（`12` §11） | 跟随系统（待裁决） | Android 平台惯例，标为 P 项 |
| D-06 | 状态栏显示磁盘剩余空间（`F1-20`） | 不显示 | Android 分区存储下该值对用户意义有限 |
| D-07 | 时间线滑块（`F1-23`） | 本版不做 | 手机用分组头 + 滚动定位足矣（见 §10） |

> ⚠️ D-04 复核说明：`docs/01` §5 的 `F5-05` 仍是**原版兼容口径的遗留文字**，但项目 v3.0 已整体作废 ini 兼容

## 10. 设计红线与非目标

| 红线 | 原型如何守 |
| --- | --- |
| **R-1 照片目录零写入** | S2 rationale、S10 关于页写明「只读、不写 ini、不改原图」；导入导出只动自家数据库 |
| **R-2 编辑室入口不存在** | S6 查看器**没有**任何编辑/滤镜/旋转写回按钮；方向只按 EXIF Orientation |
| **不引原版资源** | 图标为几何自绘 / M3 系统图标；不提取 Picasa 3.9 任何图片 |
| **不恢复玻璃态** | §1.1 明确作废，原型无彩色顶栏底图、无模糊折射 |
| **单一真相源** | §4 五处同源 |
| **失败不静默 / 不显示 ETA** | §4 状态表 |

**非目标（本原型不做，若立项再裁决）**：
- 真实 Android 工程（Kotlin / Jetpack Compose / Gradle / 复用 Rust 引擎）——本文只给界面，不写实现；
- 平板 / 折叠屏展开的双栏专属布局（手机竖屏为主）；
- 时间线滑块（`F1-23`）、并排比较（`F2-13`）、GIF 播放（`F2-14`）、视频播放器（`F2-15`）；
- 人脸聚类 / 人物 / 地点 / 地图（`F5-06～13`，桌面 M1 也未开工）；
- 编辑室、滤镜、旋转写回、打印、邮件、幻灯片成品导出；
- 深色主题像素稿、动态取色（Material You）、多语言、无障碍完整规格；
- 像素级视觉定稿（归未来 `docs/ui-baseline`）、`03` 的 `TC-ANDROID-*` 用例登记。
