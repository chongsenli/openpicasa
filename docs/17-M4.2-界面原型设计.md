**阅读说明**

- 本文是「界面原型设计」：给**屏幕线框、状态、交互流程**，把 `16` 的每条需求落到可看见的界面上；**不写像素级视觉常量**（归 `docs/ui-baseline/`），**不写实现代码**（归实装），**不写 AC 全文**（归 `16` §3）。
- 线框为 ASCII 示意，用 `┌─┐` 边框表示窗口/面板，`[ ]` 表示控件，`●` 表示角标/标记，`░` 表示 placeholder/空白格，`★` 表示星标。HTML 原型里用 CSS 还原同样的信息层级，不追求 1:1 像素。
- 屏 id（S1–S7）与 `prototypes/m4.2-prototype.html` 的 `data-screen` 一一对应，便于评审时对照点击。
- 本文所有控件沿用 **v1.8 白圆底 + 加深阴影**体系；**不出现任何玻璃/折射/vibrancy 元素**（P-M42-05 已裁决不做）。

## 0. 设计原则

| 原则 | 说明 | 来源 |
| --- | --- | --- |
| **P1 不新造视觉语言** | 所有新增控件沿用 v1.8 白圆底 `draw_control_chrome`：`control_shadow` offset[0,2]/blur6/alpha64 + `control_contact_shadow` + `control_hairline`。不引入玻璃/渐变/彩色顶栏 | R-M42-3、`13` §10.7 |
| **P2 只补「看得见」的断层** | A 组解决「能打星标却看不到」「大图圆角小图直角」这类逻辑割裂，不做新功能 | `16` A 组 |
| **P3 不抢用户操作** | 框选增强不抢滚轮；自动滚动只在拖拽中按输入事件驱动，空闲帧零额外重绘 | R-M41-1、`16` M42-UI-03 AC-04 |
| **P4 反馈明确、失败不脏库** | 新建/改名/删除/导入预览都有空态、失败 toast、二次确认；失败不产生脏记录 | `16` B/C 组 AC |
| **P5 性能可见但不打扰** | D 组基准与上传调度是内部指标，主界面**不新增常驻性能 HUD**；基准只在诊断/测试视图呈现 | R-M41-1、P-M42-10 |
| **P6 三布局一致** | 方格 / 纵瀑布 / 横瀑布：星标角标、圆角裁剪、滚动手感改动均三布局复验 | `16` §0 / R-M42-1 |

> ⚠️ **与 M4.1 原型的分界**：M4.1 的 6 屏里有 `glass` 屏（玻璃态），该屏连同整套玻璃在 v1.7 已整体回退。**本文不沿用 `glass` 屏**，也不 resurrect 任何玻璃 token。M4.2 的 7 屏是全新编号（S1–S7）。

## 1. 样式基线（继承 v1.8，锁死）

| token / 元素 | 基线 | 本版 |
| --- | --- | --- |
| 顶栏/工具栏底 | `theme.toolbar_bg`（纯色） | 不变 |
| 圆钮 / 胶囊按钮 | 白圆底 + `control_shadow` + `control_contact_shadow` + `control_hairline` | 不变 |
| 选中态 | v1.8 既有选中角标与边框 | 与星标角标**分占不同角**（§2 S1） |
| 玻璃 token（9 个） | v1.7 已删除 | **不得恢复** |
| 新增浮层/下拉/输入 | 沿用白圆底体系 + 同一阴影层级 | 不引入新视觉 |
| 字体/✓ 字形 | 已知缺 `✓` 字形（INFO「No font has "✓"」） | 角标用 `★`/形状绘制，不依赖 `✓` 字形 |

│               │                                          [托盘 0]       │
└───────────────┴──────────────────────────────────────────────────────────┘
```

**状态表**

| 状态 | 表现 |
| --- | --- |
| 无星标 | 该格右上不显示 `★` 角标 |
| 有星标 1–5 | 右上显示 `★N`（N 为星数），与选中角标 `●选` 分占不同角，互不遮挡 |
| 选中 | 左下/另角显示 `●选` + v1.8 选中边框；星标角标仍在 |
| 0 选中 + 无标签 | 左栏正常；查看器信息条不显示空占位（见 S2） |
| 新建入口 hover/点击 | 白圆底按钮 hover 阴影加深（v1.8 既有），点击后展开内联输入框 |
| 新建中（输入态） | 左栏该项位置变单行输入框 `[ 输入名称 ⏎ / Esc ]` |
| 新建成功 | 左栏立即出现新条目，toast「已创建「XX」」 |
| 新建失败（空名/重名） | 输入框标红 + toast「名称不能为空 / 已存在同名标签」，库内无脏记录 |
| placeholder→实图 | `░` 占位平滑替换为实图，不闪（M42-PERF-02 过渡要求） |

**交互**

1. 打星标 → 同格右上出现 `★N`；取消 → 消失（M42-UI-01 AC-01）。
2. 点击「＋ 新建标签 / ＋ 新建相册」→ 内联输入 → 回车落库 → 左栏刷新；Esc 取消不落库（M42-UI-04 AC-01～03）。
3. 星标/标签变更后网格同帧刷新，无需重进。

**状态表**

| 状态 | 表现 |
| --- | --- |
| 未拖拽 | 无框选矩形、无边缘带、零额外重绘 |
| 拖拽中且远离边缘 | 正常拖出矩形（M4.1 S4 既有行为） |
| 拖拽中触及边缘带 | 按距边缘梯度自动滚动，选区随滚动连续扩张；**只在拖拽中按输入事件驱动** |

│               │  │  ○ 2024 夏                        │ ← 下拉列出已有相册 │
│               │  │  ○ 家人                           │                │
│               │  │  ─────────────                    │                │
│               │  │  ＋ 新建相册…（接 M42-UI-04）     │                │
│               │  └────────────────────────────────────┘                │
│               │  ┌────────────────────────────────────┐                │
│               │  │ ⚠ 删除相册「2024 夏」？            │ ← 二次确认      │
│               │  │ 只解除相册关联，不会删除照片文件。  │                │
│               │  │            [取消]   [删除]         │                │
│               │  └────────────────────────────────────┘                │
└───────────────┴──────────────────────────────────────────────────────────┘
```

**状态表**

| 状态 | 表现 |
| --- | --- |
| 0 张选中 | 「加入相册」「标签」按钮**禁用**（合理禁用态） |
| ≥1 张选中 | 操作栏可用；「＋ 加入相册▾」列出已有相册 |
| 标签浮层打开 | 三态 `☑全选 / ▣部分 / ☐未选` 读缓存，打开帧查库次数恒定（M42-UI-06 AC-01） |
| 标签变更后重开浮层 | 缓存失效并刷新，三态正确（AC-02） |
| 加入相册成功 | toast「已加入「2024 夏」」；打开该相册可见照片（M42-UI-05 AC-01） |
| 改名 | 内联输入 → 左栏与下拉同步刷新（AC-02） |
| 删除（未确认） | 弹二次确认，文案明确「只解除关联、不删照片文件」 |
| 删除取消 / 确认 | 取消：不删；确认：相册消失、照片仍在库（AC-03） |
| 新建失败 | toast 且不落脏记录（同 S1） |

**交互**：选中照片 → 加入相册下拉选目标 → 落关联；相册 `⋯` 菜单改名/删除（二次确认）；标签浮层三态由缓存驱动，不每次查库；「＋ 新建相册…」复用 S1 新建入口。

## 4. 全局状态与反馈

| 类型 | 统一表现 | 约束 |
| --- | --- | --- |
| **toast（成功）** | 底部白圆底浮层，如「已创建「旅行」」「已加入「2024 夏」」 | 沿用既有 toast；几何钳制防御保留（M42-ROB-01 三层防御不撤） |
| **toast（失败）** | 同上 + 错误文案（空名/重名/校验失败/导入失败） | 失败不产生脏记录 |
| **二次确认** | 居中模态，白圆底 + 加深阴影；文案写明后果（删相册「只解除关联、不删照片文件」） | 取消零副作用 |
| **禁用态** | 0 选中时操作按钮置灰不可点 | 不隐藏，给「为什么不可用」的可见性 |
| **空态** | 无星无标签不显示空占位；预览缺缩略图用 `░` 占位；隔离空库短跑无内容 | 不用玻璃/渐变填充 |
| **加载/placeholder** | `░` 占位 → 实图平滑替换，不闪（M42-PERF-02） | 不引入常驻重绘 |
| **进度** | 六态文案 + 不确定/确定进度条（M42-PERF-01） | 可取消、UI 可交互 |
| **hover/聚焦** | v1.8 既有阴影加深 / 发丝边 | 新增浮层开合须配 `request_focus` / `surrender_focus`，避免 `shortcuts::collect` 见 focused 返回空吞快捷键（`16` §2.4 RK-06） |

## 5. 交互流程（文字流程图）

**F1 · 新建标签/相册（M42-UI-04）**

```
点击「＋ 新建标签」→ 左栏该项位变内联输入 → 输入名称
  ├─ ⏎ / 确认 → 校验（非空/非重名）→ 建库记录 → 左栏立即出现 + toast 成功
  ├─ Esc / 取消 → 收起输入，不落库
  └─ 校验失败 → 输入标红 + toast，库内无脏记录
```

**F2 · 加入相册与相册 CRUD（M42-UI-05）**

```
选中 ≥1 张照片 → 操作栏「＋ 加入相册▾」可用 → 下拉列已有相册
  → 选目标 → 写 album_photos 关联 → toast → 打开相册可见照片
相册「⋯」→ 改名（内联→左栏/下拉同步刷新）
相册「⋯」→ 删除 → 二次确认（「只解除关联、不删照片文件」）
  ├─ 取消 → 不删
  └─ 确认 → 相册消失、照片仍在库、不新增 schema
```

**F3 · 框选增强（M42-UI-03）**

```
按下拖出矩形（M4.1 S4 既有）→ 拖到视口边缘带
  → 按距边缘梯度自动滚动（仅拖拽中、按输入事件驱动）
  → 选区随滚动连续扩张、跨滚动位置先前选中不丢
  → 滚轮始终归 ScrollArea、不被抢
  → 松手定稿；空闲帧零额外重绘（R-M41-1）
触板三指/双指手势：不做（P-M42-04 非目标）
```

**F4 · 导入向导选前预览 + 后台导入（M42-UI-07 / M42-PERF-01）**

```
选包 → 清单 FNV 校验 → 选前缩略图预览（只读包内 thumbs，不读原图）
  → 确认 → 后台线程导入（六态 + 不确定进度条 + 可取消，UI 可交互）
  → 完成 / 失败（失败整库回滚、无残留 staging、id 平移重映射语义不变）
```

**F5 · D 组「先基准后优化」（M42-PERF-00 → 02 → 03）**

```
阶段 0.5：隔离库实测 → 固化 TC-M42-PERF-* 基线（门禁：无基准不谈优化）
  ↓（与 A 组圆角贴图阶段 1 错开归因）
阶段 2.5：PERF-02 加载速度 → 回基准复测（p99/首屏不劣化？）
  ├─ 否 → 回退该改动
  └─ 是 → PERF-03 滚动平滑 → 回基准复测 → 收口
常量 3 / 120 / 8.0 全程不动（P-M42-09）；只做调度/可见性/复用（P-M42-10）
```
